# 总纲

## 全书主线

**一句话**：一个现代仓储主管，用"后勤"二字，从河东的一粒粟起步，养活一支军队，撑起一座王府，最终喂饱一个帝国。

**三条线交织**
1. **种田经商（主线，约 50%）**：粮 → 盐 → 铁器农具 → 长安商号 → 救灾国策 → 丝路海贸
2. **权谋争霸（约 35%）**：河东战事 → 秦王府 → 夺嫡 → 玄武门 → 北伐突厥 → 门阀之争
3. **感情（约 15%）**：父女线（阿蕖）+ 柳七娘 + 康妙娜

**贯穿全书的悬念**：主角对历史的改动越多，"先知"就越不灵；他每一次死里逃生，也都要用一段未来的记忆来换。他究竟是在顺应历史，还是在创造历史？

## 各卷要点

### 卷一·龙门渡
- **开局**：魂穿成辽东老兵，官府逼着烧粮，族叔趁火打劫。
- **金手指亮相**：凭《通鉴》预知李世民渡河缺粮，冒险藏粮。
- **第一个大爽点**：柏壁献粮，而且不是白送，是用一套"粮券"制度换来秦王府的信用。
- **打脸**：族叔 → 贾家 → 裴寂（暗中）。
- **结尾**：雀鼠谷送粮，与尉迟恭结交，得到赏赐和经营盐池的机会。
- **感情**：遇见柳七娘。

### 卷二·盐池
- 改良解池晒盐，雪花盐横空出世。
- 曲辕犁、筒车在韩家坞试点。
- 与柳七娘合伙成立商号。
- 河东盐商联合打压，主角以低价加高品质反击，再借秦王府的军需订单一举翻盘。
- 后勤支援东征洛阳，虎牢之战立功。

### 卷三·长安
- 商号进驻西市，遇见康妙娜。
- 推出胰子、印刷、柜坊，一时风头无两。
- 被东宫和齐王盯上，商号遭查封。
- 平阳公主线；魏征作为对手登场。
- 主角第一次意识到：钱多了，就是罪。

### 卷四·玄武
- 均田令颁布，主角的示范庄园成为样板。
- 杨文干事件，主角险些被卷进去。
- 突厥压境，主角以边贸获取情报。
- 玄武门细节和史书出现偏差，主角第一次失去"先知"。
- 玄武门之变、渭水之盟。

### 卷五·贞观
- 贞观二年蝗灾、旱灾，主角的仓储体系救了关中。
- 义仓成为国策，主角入朝。
- 北伐东突厥的后勤，与李靖搭档。
- 封爵。与李世民的关系从赏识走向微妙的忌惮。

### 卷六·万商
- 丝路商团、高昌、西域诸国。
- 海贸南下，寻找占城稻。
- 《氏族志》与门阀终局。
- 主角功成身退，或者成为"大唐最大的东家"（结局待定）。

## 爽点设计原则

1. **信息差打脸**：别人不知道接下来会发生什么，主角知道。
2. **专业碾压**：古人管粮靠经验，主角管粮靠体系。
3. **反转收割**：反派以为抓到了主角的把柄，其实是主角设的局。
4. **大人物认可**：每卷至少一次被历史名人当众认可。
5. **财富数字**：读者喜欢看数字增长，每卷末给一张"家底清单"。
