# 第二十章　隐谷 · 章节状态

## 1. 关键事件
- 九月初二 三更：西沟北头白毡帐内召唤24人（编号277–300）；周四帐外守，阿史那、冯五在沟沿，未目睹。
- 同夜：彭四至彭七（钉掌、硝皮、编绳、剃头）；郎一至郎七；鲁一至鲁七（鲁三"攀崖"）；韦一、韦二、韦四等。郑一用炭条记在羊皮上，沈游念名。葛四发皮袍靴子。
- 丑时：褚一"走"，一百二十人、二十峰骆驼、九十来匹马，新人随后，上塬北行。
- 天发青：冯五带两人拖酸枣枝扫拐口蹄印。卯正：进隐谷。
- 辰时末：鲁三崖顶示警，哨往谷外跑，"一刻"后有人到。
- 时辰未标：突利部散骑五人进谷，阿史那以突厥话讲价。绊绳起，郑六射马前腿，卫一摔人，褚四棍扫膝弯，陈五刀背磕腕未出刃，冯六小弩钉领头马。一死四活。周四挡在沈游身前，未出手。
- 同日：俘虏称"天刚亮从小可汗营里出来""初五天亮分绢"。褚一带四人入林，原文只写"很快就没有动静了"。冯五骑两匹突利马西拖蹄印。
- 酉初：褚一定"初五天亮分绢，初四夜里"；曹一"头马只能叫一回"；周六清点莨菪，七斤。
- 同一时辰，川里：咄悉乌略数车，五骑南去未回，下令加绊索、加游哨，明早派队往南，夜里不派。

## 2. 主要人物章末状态
- 沈游：谷内南坡大石，腿内侧两处磨破，丑时后又磨开，抹过周六的药。
- 周四：沈游身后三步。
- 褚一、周六、曹一、阿史那、冯五、郑一、卫一等：谷内，伤势未提。
- 四名俘虏（含领头）：入林，结局未明写。

## 3. 人物关系变化
- 沈游与郑一：羊皮记号只郑一认得，沈游心想"单点故障"。
- 沈游与冯五：沈游说"下回扫得脏一点"，冯五记下。
- 阿史那与领头：突厥话周旋，阿史那拉满角弓，领头弃弓。

## 4. 伏笔
- 新增：郑一羊皮记号（"家里的底子，只有周一一份"；"只有自己人看得懂，倒是好事"，种子两颗）；咄悉绊索、游哨；"头马只能叫一回"；莨菪七斤；突利马印；冯五"下回扫得脏一点"。
- 回收：突利马印（阿史那验，与周一所刻印"分毫不差"；埋于第14–16章）。
