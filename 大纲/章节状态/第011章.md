# 第十一章　立后 · 章节状态

## 1. 关键事件
- 8/21（第十三日）天未亮：宫城鼓乐，立皇后。
- 子时：新召十三人，累计91。
- 辰时：窦家两车、四十只描金漆盒白糖（一百二十斤）出西门往宫城，樊大押车。
- 巳时：周一报糖坊日出一百斤、东市排队翻倍、烧春（冯二）、《开明坊凶宅记》（冯四）；崔家及城南大业坊废寺共四十来个东宫旧兵。
- 午后：钱彪从后门来报：崔郎将借巡城之名，8/23夜穿屯卫甲、打"搜突厥细作"旗号，从坊门进。沈游不改计，令钱彪照崔郎将所说去做，"不良人，一个都别留"。
- 傍晚：窦十一郎报宫里收糖，言长辈说有国公在打听糖坊东家；仍选沈游"你就是某找的路"。沈游托其8/23夜请卢县尉与左屯卫中郎将来喝烧春、看戏。
- 夜：沈宅后院家宴。
- 夜：东宫显德殿家宴。皇后尝雪糖，"白得像雪"；李世民赐名"雪糖"；长孙无忌献"拂菻宝物"打火机，李世民收入袖中。
- 夜深：泾州急报，颉利、突利合兵十余万骑寇泾州，前锋过武功；京师戒严，诸卫点检。
- 夜：沈游屋脊上观马队奔城门；"来得正好"。

## 2. 主要人物章末状态
- 沈游：屋脊上，青萝披风；伤势未提。
- 钱彪：已倒向沈游，8/23夜行事待定。
- 崔郎将（崔守礼，细纲）：8/23夜当值，计划入沈宅；章末未直接出场。
- 周四：后院月洞门下，三十人已起。
- 窦十一郎：称"请倒是请得来"，未明确应承；请帖未提。
- 李世民：出殿，去点检诸卫。

## 3. 人物关系变化
- 沈游与钱彪：钱彪"不想当那个陪着输的人"，沈游以"二十三那夜照他说的做"接收。
- 沈游与窦十一郎：十一郎违家长之令，选沈游。
- 窦家与国公：长辈有意疏远沈游。

## 4. 伏笔
- 新增：国公打听糖坊东家；紫袍五十来岁男子盯雪糖（身份未提；与第10章"国公府主人"是否同一人，待确认）；雪糖之名、拂菻火落入皇帝手中。
- 回收：崔守礼计划（第9章"京城一乱就动手"）已明确为8/23夜。

- 下章接住：8/22起，8/23夜前的准备；突厥进逼。
