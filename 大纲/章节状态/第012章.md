# 第十二章　十日之期 · 章节状态

## 1. 关键事件
- 8/23（第十五日）子时：新召十五人，累计120。
- 二更：崔守礼率四十一人，穿左屯卫甲，从正门叫门"搜检突厥细作"；赵坊正开门。
- 门内：中郎将宇文彦出面，称"本卫今夜，没有发过搜检民宅的牒"，指认崔部"没有一个是我左屯卫的兵"。卢县尉、窦十一郎在场。
- 崔守礼拔刀喊"鸦"，沈游敲扶手；二十四盏琉璃灯亮，大门闭死，伏兵四出。张横、韦三、孙老鸦被擒；崔守礼被陈五刀抵喉，弃刀。
- 外院：刘九弩队被冯六箭射右小臂，冯五绕后得手；撤往坊门的二十人被钱彪截住，冯七率众迈步压阵，二十人放刀。
- 崔守礼："崔某贪财。"沈游许诺："盒子，我不交出去，也不烧。我留着。"
- 8/24 子时（第十六日）：新召十六人，累计136。
- 四更：左屯卫百人到，宇文彦押四十人出坊；急报东宫。
- 同时，东宫显德殿：李世民读急报，"等突厥退了，朕要见见这个和尚"。

## 2. 主要人物章末状态
- 沈游：寝堂，天亮后入睡；伤势未提。
- 崔守礼：被反绑，随宇文彦押出（推算）。
- 张横：右腕被拧，后脑磕台阶，被擒。韦三：肋下受撞，被擒。孙老鸦：左肩被卸，被擒。刘九：右小臂被射穿，被擒。
- 东宫旧兵死二人（姓名未提）。
- 周四：小臂两寸刀口，周六缝合；原文未写哪只手。
- 沈家伤：冯五手下一人肩中弩；另一人头皮擦伤。

## 3. 人物关系变化
- 沈游与崔守礼：沈许诺"谁也别想拿它杀人"，崔问"包括我？"，答"包括你"。
- 沈游与宇文彦：宇文称沈家护院"个个能当队正"；临走约"改日再来喝完"烧春。

## 4. 伏笔
