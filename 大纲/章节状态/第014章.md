# 第十四章　泾阳 · 章节状态

## 1. 关键事件
- 8/25（原文未标时辰，承上章晨）：沈游不去泾阳（"核查期间，沈游不得离京"），点人派出；郑三算车牛约百贯，沈游："回本的，不是车。"；周一提县里和雇簿车主一栏写沈游之名。
- 8/25 午时：西市买牛二十头（七十贯）、车二十辆（四十贯）；书手写"开明坊沈游，车二十乘"。
- 8/25 未时：车队出开远门，装米二百石，押粮仓曹独孤某。
- 8/25 酉时：过中渭桥，天黑前卸粮于北岸粮台。
- 8/25 夜：汤池，周一报陈六回：薛国公府无动静；沈游想起"渭水、便桥、六骑"，想不出是哪天。
- 8/26 子时：新召十八人，累计一百七十一。
- 8/26 辰时：北方三四股黑烟，郑六判为烧村。
- 8/26 午时：快马报"泾阳大捷"过粮台；独孤借沈家二十人押骡二十头送胡饼、麨。
- 8/26 未时：坊人至沈家门口，周一出面："郎君说，进不来。"
- 8/26 申时：阿史那持放良书至沈家，沈游定月钱一贯，入雇。
- 8/26 擦黑：阿史那称突厥"后天，可汗到渭水"；沈游定明日派阿史那、郑一去渭桥接人。
- 8/26 酉时至二更：驮队至泾阳粟地；日落后雾起，曹一哼调，突厥马群出芦苇聚到他身边；梁果毅定缴获归官四十七匹，伤马二十四匹付沈家；驮队宿空村，冯五守头班，褚一、郑六望见东北塬那头火堆三千多。

## 2. 主要人物章末状态
- 沈游：8/26 擦黑仍在后院；伤势未提。
- 驮队（褚一、曹一、郑六、冯五、冯三等）：8/26 二更在泾阳空村；伤势未提。
- 孟大郎：府兵，左臂箭伤，一火十人折一伤三；托冯五带话，章末未提。
- 阿史那：入雇，在后院看马厩，次日随郑一去渭桥。
- 郑一：在东院，次日去渭桥。
- 郑三：8/26 带阿史那去坊正家登名，章末未提。
- 周一：8/26 擦黑后去找陈六，安排盯阿史那。
- 阿娜：8/26 廊下调弦，手停在弦上。
- 梁果毅：右臂吊胸，河滩上认出马群"是马变的吧"。
- 吴管家：8/25 整天未出府门；8/26 未提。
- 青萝、周三、周四：章末未提。

## 3. 人物关系变化
- 沈游与阿史那：沈游"我家不兴这个…要来，就是雇"；阿史那欲跪，被周四托住。
- 沈游与裴家：阿史那带话"粮行的事，不是裴家的意思"；沈游定"不藏"，任人告状。
- 周一与沈游：周一担心金吾卫被人递状子；沈游："他想得到，薛国公府也想得到。"
- 沈家与驮队：独孤两问"你们东家做什么营生"，沈家答"卖糖"。

## 4. 伏笔
- 新增：突厥"后天可汗到渭水"；"渭水、便桥、六骑"；金吾卫抓粟特人"细作"；县簿车主写沈游名；突厥马群随头马走（曹一认头马）；孟大郎："可汗还在后头"；郑六得突厥弓，箭有鸣镝。
- 回收：孟家大郎下落（泾阳找到）；阿史那承认粮行之事非裴家本意。
