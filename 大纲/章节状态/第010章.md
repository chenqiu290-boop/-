# 第十章　大赦 · 章节状态

## 1. 关键事件
- 第十二日（"明日，八月二十一"，推算8/20）辰时：子时新召十二人，累计78；县吏持牒上门，首告人柳七（裴家门客）告沈游诈冒僧籍。
- 辰时过半：沈游定策，以八月初九大赦、私度不在十恶之列为据。
- 午前：冯五找城南老农作证；冯四打听兰若；周一抄录赦书；赵坊正呈五月十七日拆庙底账（"僧三人，已遣散"）；刘嫂作证。午时冯四回报兰若老和尚与三徒弟去向。
- 未时：万年县廨对质。柳七称祠部僧籍无沈游，也无其附籍时所报师父法号"慧明"；沈游答兰若本不在祠部籍上。卢县尉判"于律无碍"，移文益州，沈游"核查期间不得离京"；诬告反坐，警告柳七。
- 日暮：柳七称"裴家不会再走县里的门了"。
- 夜：阿娜在两尺圆毯上跳胡旋；沈游称"十日之期，还剩三天"。
- 同夜：东北大宅偏厅，裴十三献策；上首未具名男子说"没人，才好办"。

## 2. 主要人物章末状态
- 沈游：夜在后院摇椅；不得离京；伤势未提。
- 周一：派两人明早城门开即赴益州（人选未提）。
- 青萝：后院煎茶；伤势未提。
- 柳七：县廨受挫，"谨受教"，去向未提；心中想过附籍文书真伪，未当庭追问；目光在沈游垂着的右手上停了一停，未开口。
- 老农：儿子"前日"被调往北边（未具名，第13章称孟老丈）。已核实："前日"指8/18，与第13章"走后六天无信"一致，不构成矛盾。
- 老和尚：法号慧明（沈游附籍时所报师父法号），已病死，葬庙后坟地。

## 3. 人物关系变化
- 沈游与柳七：柳七由淡漠变"有了点别的东西"；章末沈游问"会走哪扇门"，柳七不答。
- 沈游与卢县尉：县尉以"县里办得没错"接受赦后附籍。

## 4. 伏笔
- 新增：兰若另两徒弟（蒲州、终南山）去向；窦家宫宴糖（沈游称"昨晚才定"，青萝存疑，待确认）；国公府主人露头。
- 新增（可能的后续线索）：柳七想过附籍文书真伪，益州一来一回需两月；柳七的目光在沈游垂着的右手上停了一停，没有开口，原文未说明他的具体疑虑。
- 回收：细纲称第1章大赦、破庙与老农在此回收（正文未直说）。
