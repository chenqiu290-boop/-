要审查的章节和重点：$ARGUMENTS

1. **确定章号**：从参数取章号 N，补成三位数 NNN。参数缺失或不是章号，就停下来问作者。
2. **核对资料是否齐全**（用 Glob，只查存在与否）：
   - 正文：`正文/第NNN章 *.md`
   - 上一章状态：`大纲/章节状态/第(N-1)章.md`（三位数，如审查第 14 章查 `第013章.md`）
   - 细纲：`大纲/第一卷细纲.md`（第 N 章在第 1–20 章范围内；超出就先问作者当前卷细纲在哪）
   - 第 N 章正文不存在，或上一章状态文件缺失（第 1 章除外）：**停下并报告缺什么**，不要猜，也不要自动生成。上一章状态缺失时，告诉作者可以先让 chapter-indexer 补上，由作者决定。
3. **调用 `logic-reviewer`**（Opus），传入章号 N 和作者的重点。不要通读其他章节。
4. **核实**：对报告里的高、中档每一条，回到原文核实被引的那几行，确认引文和依据属实。
5. **汇报**：向作者输出审查结果，分高、中、低三档，每条写明位置、依据、影响、最小修复建议；核实后不成立的条目单列并写明理由；"需作者确认"和"文风偏好"分开列出。
6. **不修改任何文件**，不保存报告，不自动改稿。作者确认要改哪几条后，再另行安排。
