---
description: 检查第 N 章的连续性（Haiku），主会话逐条核实后报告；不改文件
argument-hint: <章号> [要重点查的事项]
---

要检查的章节和重点：$ARGUMENTS

1. 从参数取章号 N，用 Glob 确认 `正文/` 下有第 N 章文件。
2. 用 Glob 查 `大纲/章节状态/第(N-1)章.md` 是否存在（三位数章号，如 `第013章.md`）；已存在就直接用，不重复生成；不存在才调用 `chapter-indexer` 处理第 N-1 章。
3. 调用 `continuity-checker` 检查第 N 章，把作者给的重点一并传过去。
4. 对报告里每一条，回到原文核实（只读被引的那几行）。
5. 向作者汇报：成立的问题（附原文和建议改法）、驳回的条目及理由。
6. 不修改任何文件。作者确认要改哪几条后，再调用 `chapter-writer` 按清单最小改动。
