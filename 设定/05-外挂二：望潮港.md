# 外挂二：望潮港

## 一句话

**主角脑子里有一座无人的现代超大型货运港口，几十万个集装箱，几乎什么都有，但全都封着、没有标签、没有电。想要什么，得他自己一箱一箱去翻。**

这个外挂和主角的职业是咬合的：别人拿到一座港口只会瞎翻，他是干了十年仓储的主管，懂箱号、懂箱型、懂唛头、懂舱单，**他翻得比谁都快**。

---

## 一、港口是什么

- **名字**：望潮港（虚构），主角所在物流公司的合作港口。穿越前三天，他就在这里的驻港仓库加班盘点。
- **状态**：定格在他穿越的那一刻。天永远是阴沉沉的白昼，海面不动，没有风，**一个人都没有**。
- **没有电**。岸桥、龙门吊全都停着，电脑开不了机。只有几台柴油叉车、正面吊和备用发电机能手动启动，柴油有限。

### 港区布局

| 区域 | 内容 | 用处 | 何时开放 |
|---|---|---|---|
| **A. 集装箱堆场** | 几十万个箱子：日用品、五金工具、服装、电子、家具、机械零件、化肥、药品、种子……完全随机 | 主体，"翻找"的主战场 | 卷一起，分区块逐步开放 |
| **B. 冷藏箱区** | 肉、海鲜、水果、**鲜土豆**、药品冷链 | 救急，也有一批会发芽的土豆 | 卷一 |
| **C. 散货码头** | 粮食筒仓（进口**玉米、大豆**、小麦），铁矿石、煤炭堆场 | 种田线的核武器 | 卷二 |
| **D. 港区生活区** | 办公楼、档案室（纸质舱单、提单）、食堂、便利店、员工宿舍 | **档案室是港口的"索引"**，找到之后翻找效率大增 | 卷三 |
| **E. 危险品堆场** | 化工原料（烧碱、硫酸等）、烟花爆竹、电池 | 制皂、开山、信号 | 卷四 |
| **F. 泊位巨轮** | 一艘靠港的集装箱船，驾驶台有**海图**、罗盘、六分仪 | 卷六海贸的钥匙 | 卷六 |

> "何时开放"是作者控制节奏的阀门。未开放的区域，他走过去会被一片浓雾挡住。

## 二、怎么进、怎么出

### 进港
- 入睡时，他可以选择"进港"。**只有意识进去**，进去后是他现代的身体；唐朝那边的身体留在原地昏睡。
- 在港里待多久，就等于睡了多久，但**醒来以后像一夜没睡**。
- 连续进港三夜以上会头痛欲裂，身体会强制他好好睡一觉。
- 箭疤的疼痛能传进港里。外面一有危险，他会被直接疼醒、拽回来。
- 保底触发后的昏迷期间进不了港，那时他在梦里的辽水边。

### 带东西出来
- 醒来时**手里拿着的东西**，会跟他一起出来，出现在身边。
- **每晚只能出来一次。**
- **只出不进**：唐朝的东西放不进去。港口不能当仓库，也不能用来瞬间运货。
- 能带多少，取决于他**盘点**的进度：

| 阶段 | 能带出的量 | 解锁条件（写作参考） |
|---|---|---|
| 一阶 | 双手拿得住的（一两件） | 初始 |
| 二阶 | 一个人背得动的（约五十斤） | 盘清第一个堆场区块（卷一中后期） |
| 三阶 | 一副担子或一头驴驮得动的（约两百斤） | 卷三，找到档案室并建立索引 |
| 四阶（封顶） | 一辆牛车的量（约一千斤） | 卷五 |

> **盘点即升级**：他在港里每打开一个箱子，都要在办公楼找来的账本上登记箱号和货物。一个区块盘清了，带出的上限就提高一级。这既是升级系统，也是他的职业本能。

## 三、限制（保证"不过于无敌"）

| 限制 | 说明 |
|---|---|
| **东西有限，用一件少一件** | 港口不会补货。真正的财富，是**照着样品让大唐的工匠造出来**，是把种子种成一片庄稼 |
| **东西会坏** | 港里的时间和外面同步。没有电的冷库，肉几天就臭了；鲜土豆几个月后会烂；药品、种子都有保质期。**这是卷一、卷二的倒计时** |
| **没有军火** | 这是民用港口，枪炮不走这里。危险品区的东西，主角自我约束，只用于开山、信号、制皂 |
| **大件出不来** | 汽车、拖拉机、工程机械都出不来。就算拆成零件，也没有燃料、没有配件 |
| **查不了历史** | 港里所有记载唐以后中国历史的文字，一律模糊不可读。未来的历史只能靠残卷知道，**撕书的代价照样成立** |
| **读书很贵** | 港里偶尔能翻到书（教材、农技手册），他可以在里面读，记在脑子里带出来。但每晚时间有限，读书就没时间翻找，而且书在货物里极少 |
| **来历是麻烦** | 塑料、不锈钢、印刷标签，在唐朝都是"妖物"。每样东西都得去掉标签、换包装，对外说是"海外胡商的奇货"。被人识破，轻则被抢，重则以妖言论罪 |

## 四、翻找怎么写才好看

1. **开箱是固定爽点。** 每次开箱都像拆盲盒：一箱拖鞋、一箱圣诞彩灯是"空军"，一箱钢锯、一箱化肥就是"大奖"。读者会跟着期待。
2. **职业知识就是翻找技巧。** 冷藏箱一定带制冷机组；罐箱装液体；开顶箱多半是钢材、石料；箱门上的唛头写着发货地，看得懂就能猜货。他越翻越准。
3. **样品比数量重要。** 一把钢锯，让周铁头琢磨三个月，大唐就有了好锯；一把土豆种下去，三年后就是一县的口粮。**港口给的是火种，烧起来靠他的组织能力**，这守住了"靠后勤、靠组织"的全书卖点。
4. **港口是一个人的孤独。** 偌大的港区只有他一个人，他偶尔会在便利店里坐着发呆，喝一罐过期的可乐，想家。这是现代记忆的锚，也是"撕书"代价落到现代记忆时最疼的地方。

| 一 | A 区 | 一卷塑料薄膜 | 粮窖防潮 |
| 一 | A 区 | 一箱五金工具（钢锯、锉刀、游标卡尺） | 给周铁头当样品，曲辕犁提速 |
| 一 | A 区 | 一盒阿莫西林 | 救命用，只有几十粒，用一粒少一粒 |
| 一 | B 区 | 一冷藏箱已经发芽的鲜土豆 | **抢在烂掉之前种下**，卷一末首次收获，亩产震惊全村 |
| 二 | C 区 | 筒仓里的进口玉米、大豆 | 玉米种下去能长，但商品粮的后代不整齐，要连年选种、留种。这是一条好写的种田支线 |
| 二 | A 区 | 一箱蔬菜种子（辣椒、番茄、南瓜……） | 种子几年后就会失去活力，**要抢时间种、抢时间留种** |
| 三 | D 区 | 档案室、纸质舱单 | 建立索引，翻找效率大增 |
| 三 | A 区 | 少量农技、化学教材 | 在港里读，记在脑子里带出来 |
| 四 | E 区 | 烧碱、烟花 | 制皂；信号（是否用于玄武门，视剧情定） |
| 五 | — | 早年的种子大多过了保质期 | **靠的是卷一、卷二就开始留种**，前期铺垫在这里兑现 |
| 六 | F 区 | 巨轮驾驶台的海图、罗盘、六分仪 | 南下寻找占城稻 |

## 六、与"箭疤与残卷"的关系

| | 箭疤与残卷 | 望潮港 |
|---|---|---|
| 管什么 | 命和情报 | 物资和样品 |
| 代价 | 撕掉未来的记忆 | 睡眠、时间、有限的库存、暴露的风险 |
| 来历 | 辽东袍泽（卷六揭示） | 未解之谜，可以与辽东线合并，也可以永远不解释 |

两个外挂互不替代：港里的药救不了必死之局，残卷也搬不出一粒种子。
