# 写作规范

> 作者对文风的硬性要求，全部【已定】。写每一章前过一遍。

## 零、冲突、铺垫与爆点（最优先）

**每章都要有：**

1. **推进**：主线或支线往前走一步，读者知道得比上一章多。
2. **张力**：可大可小。悬念、威胁、较量、试探、危险逼近都算，不一定是正面冲突。
3. **章末钩子**：新的威胁、新的谜、新的对手，让人想点下一章。

**大爆点隔两三章来一次，爆点之前一定要铺垫：**

- **埋**：先让读者看见危险和对手的布局（谁想要什么，为什么，打算怎么做）。
- **压**：压力一章一章往上加，对手聪明、有手段、有退路，主角的处境看起来越来越紧。
- **蓄**：读者知道主角的底牌（死士的本事、人数、把柄），对手不知道。
- **爆**：底牌亮出来，干净利落，不拖泥带水。
- **收**：写对手和围观者的反应，主角本人轻描淡写。
- **喘**：爆点之后给一章松弛：享受、日常、收获，顺便埋下一轮的线。

**对手要成熟：**

- 动机是利益、自保、家族、秘密、仕途，不是鸡毛蒜皮的私怨。
- 手段要像真实的聪明人：讲体面，走官面、走规矩、借势，能不撕破脸就不撕破脸；真动手时有准备、有后手。
- 对手输了也有体面的退法，会记住、会再来，而且下一次更难对付。

**外挂要变成看得见的震撼**：死士每天都在变多。对手第一次来见到几个人，第二次来见到十几个，下一次见到几十个、上百个，逐级加码。但这种震惊要留给爆点用，不要每章都用。

**同一种爽法不要连着用**：比如上一章靠射箭镇场，下一章就换路数（智取、借势、规矩、舆论、人数）。

**节奏：**

- 买东西、办手续、走路这类流程，能一句话交代就一句话交代。
- 日常和享受是奖励，放在张力之后。
- 对手一级一级往上升：泼皮 → 不良帅 → 权贵子弟 → 权贵 → 朝廷 → 突厥可汗。每打下一个，引出更大的一个。

## 零点五、放开写（最优先之二）

- **文风要大胆。** 敢写大场面、大排场、狠手段；敢让主角狂一点（狂而不傻）；敢让手下当着满城人的面露一手。不要处处收着，不要事事解释流程，不要怕"太爽"。
- **时间该跳就跳。** 三天的营造、五天的经营，一段蒙太奇带过，把笔墨留给有画面的场景。
- **人散出去，主角不亲力亲为。** 人越来越多，围在主角身边的只留护卫和内宅；其余各领一摊（糖坊、酒坊、点心铺、说书、情报、商路、营造、护院），去赚钱、做事、发展势力。
  - 主角的日常是：躺着听汇报，一句话拍板，然后去享受。
  - **手下厉害，就显得主角厉害。** 可以切到手下的视角写他们办事，写外人见到"沈家的人"时的震惊。
  - 每一摊都能带出新事件、新对手、新人物。
- **主角的宅院要奢华安逸，有画面感和体感。** 写清摆设、材质、光线、温度、气味、声音、手脚碰到的触感（波斯毯踩上去陷进半寸、汤池的水烫得刚好、纱帐透进来的晨光、博山炉里的沉香）。宅院跟着势力一起升级、扩建。
- **去暮气，要火气（自第14章起加码）。** 句子要有劲、有血性、有笑声：敢用重词、狠词、浪词，敢写张扬、挑衅、当面打脸、众目睽睽下的痛快。主角的狂放要落在动作和台词上（该拍案就拍案，该大笑就大笑，该一句话压住全场），不要写成温吞的"淡淡一笑""微微颔首"。叙述少用"仿佛""似乎""不禁""缓缓"这类垫词和老气横秋的感叹；少写沉吟、叹息、回想往事；对手可以怕、可以怒、可以炸，场面可以乱、可以烫。底线不变：狂而不傻，对手不降智，逻辑三遍查法照过。

## 零点六、打斗描写

- **专业**：讲战术（站位、诱敌、包抄、关门打狗、遮光与亮光）、讲兵器（横刀、齐眉棍、弩、角抵、擒拿各自怎么用、打哪里）、讲甲（披甲的人打哪里有效：手腕、膝弯、脚踝、甲裙下的大腿）。
- **干练**：动作要短，一句一个动作，一个动作一个结果。不写"大战三百回合"。
- **有特色**：每个死士的打法、兵器、习惯都不同（周四卸关节，褚四一棍一跪，卫一摔人前说"得罪"，陈五收刀前先擦两下，郑六射腿不射身）。
- **对手是狠角色**：东宫老兵、禁军、突厥骑兵都有经验、有配合、会应变、会反扑。主角这边赢，是因为更专业、准备更足、人更多，不是因为对手犯傻。
- **战术逻辑要通**：比如要留活口，就得用棍、网、摔、擒拿、射腿；不杀人制住披甲老兵比杀人难，正好显本事。
- **伤亡真实**：死士也会挂彩，对手也会死人。写清谁伤在哪里、谁救的。
- **要有旁观者的眼睛**：用懂行的人（武将、老兵）的视角点评一句，比作者自己夸十句管用。

## 零点七、侧写与派头

**配角戏份适量加，从侧面立主角。**

- 主角的分量，多从别人眼里出来：坊里人在井边传的话、老农心里的账、对手管家回去怎么复命、窦十一郎的脸色。别人越是懂行、越是见过世面，他们的一个停顿、一次改口就越有分量。
- 侧写要合理：每个人只能看见他站的位置看得见的东西，只能用他自己的阅历去判断（管家看门房、看茶、看灯，老农看斗、看钱，坊正看那一脚）。
- 配角有自己的戏：有自己的家计、心事和小算盘，主角只是他们日子里的一件事。

**表情和动作要细。**

- 用动作和表情代替"他很紧张""她很高兴"：拇指绕钱袋的绳子、算筹停在半空、簸箕掉在地上、玉韘停住、茶碗停了一息。
- 一个人物一两个固定的小动作，紧要关头这个动作一变，读者就知道他心里变了。

**主角的派头随着势力一步步长，要有格调。**

- 派头从"一整套人"身上出来，不从主角嘴里出来：门房怎么揖、客人等多久、婢女什么时候起身送客、琵琶弹完一句才停。主角自己话越来越少，动作越来越小（一根手指、一个眼神、茶碗放在扶手上）。
- 格调是：对下宽厚（给老农公道价、给邻居赔礼、不卖身边人），对上不卑（不起身、不收人情、照价付钱），有分寸（不摆阔、不骂人、不当众让人下不来台）。
- 讲究在细处：清茶、越窑青瓷、犀角梳、兰亭屏风、沉香，不堆金子。
- 派头要一步一步长，每章只往上走一小格，并且留下对照：第三章走窦家的侧门 → 第十三章窦家伯父请他"走正门"，他说"等突厥退了"。
- 派头不是傲慢。礼数照样周全，只是不再迁就。

## 零点八、主角要有活人感：多戏份、游玩、出行与插曲

**主角正面戏份要多，不能只靠别人转述。** 每章主角至少有几处自己的表情、小动作、随口一句闲话，让读者"看见他"，而不只是"听说他"。

- 表情动作具体到身体：挑眉、咬一口胡饼被烫到、靠着车辕打哈欠、把玩一枚铜钱、看到有趣的东西眼睛亮一下、被人说中心事时摸鼻子。写他怎么玩、怎么馋、怎么懒，也写他认真时手上忽然静下来。
- 他是来玩的：每隔几章安排一段"玩"——逛东西市、听胡姬唱曲、尝新摊子、看杂耍、踏青、登高、郊外跑马、夜里看灯。玩是真玩，有吃有看有闲聊，不是借游玩办正事的壳；正事若顺带发生，也要是玩的时候自然撞上的。
- 现代人的习惯和唐人的新鲜感并存：他会下意识想拍照、想点外卖、嫌路颠，但不乱说现代词；看到唐人的东西是真觉得有意思。

**出行要有派头，也要有安全，器物由手下人自己造。**

- 车马、伞盖、坐具、食盒、暖炉、行军小榻、可折叠的帐幕、隐蔽的护具，写成死士里的匠人（木匠、铁匠、皮匠、绣工等）按各自宗师级技能定制，每件有来历、有巧思，不堆金，讲究实用和细处。
- 护卫不扎眼：人数散在前后左右，外人看不出是"护卫"，只觉得这位郎君身边的人个个站得稳。要有分工和暗号，遇事先护人、再处理事，不让主角真陷险境。
- 出行路线、时辰、带多少人，要合乎当时的城防、坊禁、宵禁和人数增长表，不能为方便剧情随意违反。

**插曲丰富主线空隙，但必须合乎逻辑。**

- 插曲可以是路遇的小人物、一桩邻里小事、一个有趣的摊贩、一次小误会、一个对手的探子被轻轻接住；要么给世界添生活气，要么给后文埋小线，要么给主角性格添一笔。
- 不抢主线、不降智、不为插曲而插曲；插曲里出现的人和事，用状态文件登记，方便后文回收或收束。
- 同一种玩法不连用；玩的章节仍要有推进、张力和章末钩子。

## 一、基调

- 对话要鲜活，整体要欢快。
- **欢快不等于犯傻。** 笑点来自机锋、反差、人物各自的算盘，不来自尖叫、哭嚎、出洋相。
- 少用网络烂梗。主角心里可以吐槽现代事物，但嘴上说的话，唐人要么听得懂，要么听不懂也不出戏。

## 二、主角的底气

- 外挂只要求他活着，人数每天都在涨。**只要稳住，天下早晚是他的。**
- 所以他骨子里不怕。面对皇帝、权贵、刀兵，都从容，带着点看戏的笑意。
- 不怕不等于莽。他不作死、不冒进；避开麻烦是因为"犯不着"，不是因为怕。
- 天下是他的，跟坐不坐龙椅是两码事。椅子谁爱坐谁坐（不当皇帝）。
- 不大惊小怪，不手忙脚乱。高兴可以，不失态。
- **他是来玩、来享受的。** 随性，图舒坦：吃好的、睡软的、洗热水澡、有人煎茶梳头弹琵琶。不纠结，不苦大仇深，遇事想的是"怎么更舒服、更好玩"。善待身边人，但不说教。

## 三、配角

- **所有配角都不降智。** 每个人有自己的想法、立场和算盘，做事讲逻辑。
- **死士**：忠诚是绝对的，但不是应声虫。会出主意，会说"不"，会讲理由；主角觉得对才照办。
- **唐人**：老农、胡商、权贵、皇帝，都按自己的身份和利益行事。可以认错人，但推断要有依据。
- **对手也要聪明。** 主角赢，靠的是外挂和脑子，不是对手犯蠢。
- 自检：把这个配角换成一个真实的聪明人，他会这么说、这么做吗？

### 活人感

- **唐人配角是真正生活在唐朝的人**，不是给主角递话的工具。他们在过自己的日子：有营生、有家计、有烦心事、有口头禅。
- **让他们谈自己的事**：粮价、租调、府兵番上、突厥的风声、新天子、大赦、沙汰僧尼……这些就是唐人嘴里的"时事"。
- **一两个具体细节就够**：卖驴买麦种的钱、嫌烫的胡饼、"庙后那片坟夜里有狐狸"、掷木子前往手心吹口气。
- **他们彼此之间也有来往**：坊正和卖饼的吵价，武候跟同伴嘀咕，赌客互相起哄。不是所有人都围着主角转。
- **他们用唐人的眼光看主角**：凭短发猜他是和尚，凭手上没茧猜他不干活。推断依据是唐人的常识，不是作者的上帝视角。
- **死士同理**：有脾气、有小习惯、有自己在意的事（周三心疼柴火钱，周二不赢卖驴的钱）。
- **主角的现代常识要在线**：烧开水、卫生、算账这类事他自己知道，不用配角来教。配角能补的，是他不知道的唐朝门道和专业细节。

### 现代人与唐人的差异

主角是现代人，心理和习惯跟唐人不一样。这种差异是天然的爽点和笑点，但要**合理**：主角不说教、不显摆，唐人的反应也要符合唐人的逻辑。

| 层面 | 主角的现代习惯 | 唐人的反应 / 能做成的爽点 |
|---|---|---|
| 观念 | 不信鬼神、不怕凶宅 | 唐人避之不及的凶宅，他低价买下；唐人用"和尚念过经，镇得住"替他圆上 |
| 观念 | 对皇权、门第没有敬畏 | 见权贵不慌，唐人摸不清他的底 |
| 观念 | 把下人当人：说"辛苦"、不让跪、给月钱和休息日 | 奴婢、仆役震惊，忠心是自己挣来的；成了长安有名的"好东家" |
| 观念 | 契约意识，逐条看契 | 唐契本就有保人、罚则，他看得比唐人还细，牙人不敢糊弄 |
| 生活 | 刷牙（唐人嚼杨柳枝）、天天洗热水澡 | 让周五做猪鬃牙刷、修浴房，以后都能变成生意 |
| 生活 | 坐不惯跪坐，腿麻 | 唐人以为"和尚盘腿惯了"；让周五照着寺里的绳床做高椅高桌，日后在权贵里风靡 |
| 生活 | 按"小时、分钟"想时间，一天吃三顿 | 先说漏嘴，再改口说"刻"；周三嘀咕伙食钱 |
| 本事 | 算账、比价、看房（采光、排水、邻居、隐私） | 牙人和卖家发现糊弄不了他 |
| 本事 | 程序员式做事：拆任务、画图、写清楚 | 周五看了他画的宅院图，说比将作监的图还细 |

- 差异要一点点渗出来，不要一章堆满。
- 他可以在心里吐槽，嘴上说的话唐人要接得住。
- 唐人觉得他怪，会用唐人的常识给他找解释（和尚、蜀中风俗、出过远门），不会一下子猜到他是穿越者。

## 四、环境描写

- **目标是代入感**：让读者觉得"我在唐朝"。多写看得见、听得见、闻得见、摸得着的细节：黄土路上的车辙、槐树荚、驼铃、胡饼炉子的焦香、坊门的吱呀声。
- **长安布局要自然带出来**，不要整段讲解。办法：
  - 跟着人物走路写：从哪个坊出来、上了哪条街、路过什么、拐向哪里；
  - 用主角的现代眼光对照：朱雀大街比长安街还宽，坊像门禁小区，大街上一家店都没有；
  - 让布局和情节挂钩：坊门几时关决定能不能回家，赌坊为什么只能开在暗处。
- 每章至少有一处让人"看见长安"的段落，但不喧宾夺主，节奏照样要快。
- **细节要具体，越细代入感越强。** 地方写清大小（占地几亩、几进、几间、多高多宽），人写清有多少、站在哪，东西写清多少钱、什么材质、什么颜色。人越来越多，住处够不够住要算得清。
- **空间要合理。** 人物在哪儿、能看见什么、听见什么，要符合房子的格局（比如在后院灶房，就看不见前头正堂里的事）。
- 布局、街名、城门、作息以《长安城》为准，写之前查一下，前后保持一致。

## 五、婢女

- 婢女是主角享受生活的重要一环：煎茶、梳头、熏香、更衣、弹琵琶、陪他说话解闷、打理内院。
- **要写得真实、漂亮。** 每人一套具体的外貌（脸型、眉眼、肤色、发式、衣着、手、声音、站姿），一段来历，一门本事，一种脾气。美要美得各不相同。
- 她们是活生生的唐人：有自己的心思和顾虑，会试探新主人，会想家，会有小脾气，被善待后的反应也各不一样。
- 写得体面，不写感情戏（主角无感情线）。

## 六、称呼（按唐朝习惯）

| 场合 | 称呼 |

| 死士、奴婢称主角 | 郎君（以后成了一家之主，可称"阿郎"） |
| 死士自称 | 仆（周一这类读书人）、某；对外人可称"小人" |
| 奴婢自称 | 奴、婢子 |
| 外人称主角 | 沈郎、沈郎君；熟了按排行称，如"沈三郎" |
| 称年轻男子 | 郎君、小郎 |
| 称女子 | 娘子；按排行称"某娘"，如周三人称"三娘" |
| 称老人 | 老丈、阿翁（男），阿婆（女） |
| 称僧人 | 师父、法师 |
| 称父母 | 阿耶、阿娘 |
| 臣子当面称皇帝 | 陛下 |
| 宫人、近臣私下称皇帝 | 圣人、大家 |
| 百姓称皇帝 | 天子、圣人 |
| 平辈之间客气 | 足下、某兄；按排行称，如"张三郎" |
| "主上" | 专指皇帝，私人之间用要犯忌讳 |

死士的名字"周一、周二、周三"，唐人听来就是周家排行老大、老二、老三，再自然不过。名字里藏着"星期几"，是主角自己的暗梗。

## 七、逻辑自检（每章写完必须过一遍，过完再交稿）

**怎么查：至少过三遍，每遍只盯一类问题。**

1. **排时间表**：把本章每一场按时辰排出来（几时、在哪、谁在场、谁不在场），看先后有没有颠倒、一个人有没有同时出现在两处、坊门和市门开没开。
2. **核数字**：人数、钱、粮、天数、距离、重量逐个算一遍（一个人背不动两石粮，一个院子挤不下三十个人，四百三十石不是几百户）。
3. **查出处**：每一句消息、每一个名字、每一个判断，问一句"他是怎么知道的"，答不上来就补出处或删掉。
4. **换位置**：站到每个对手和配角的位置上，问"我是他，会不会这么做、会不会想不到"；人物嘴里的夸张可以有，叙述里的夸张要删。
5. **对前文**：跟前几章的称呼、物件、伤势、时间、地点对一遍（谁住哪个坊、哪天被征、哪道门在哪边）。

**查的内容：**


- **时间**：今天是第几天、几时；坊门、市门开闭的时间对不对；离"十日之期"等期限还剩几天。
- **人数**：人早就散在各处（糖坊、酒坊、铺子、城南、夜里的眼睛），任何外人都不可能在院子里一眼数清，只能从旁证推算（粮、车、锅、铺子、窖），或者直接问；死士累计数对不对（第 N 天 = N(N+1)/2）；场景里在场的是哪几个人；数目前后一致（比如"十个人"要数得出来是谁）。
- **钱**：进项、花销、余额前后对得上。**主角不缺钱**：死士本事高，来钱快；钱的压力只来自人数平方级增长带来的长期开销（第三十天一天九贯、第一百天一天一百贯），不写"今天吃不上饭"这类假危机。
- **信息**：每个人知道什么、是怎么知道的。名字、消息、推断都要有出处（比如周日叫得出张小乙的名字，是因为趴在野蒿里听见了）。
- **动机**：每个人为什么这么做；换成真实的聪明人会不会这么做；明显该问的问题（"他为什么不自己买下宅子"）要在文中有交代。
- **对手的要命一问**：聪明的对手一定会问到主角最怕的那个问题（"另外两个徒弟在哪"），要让他问出来，主角要接得住；接不住的地方留作后患，不要假装对手想不到。
- **对手的布局**：主角想得到的路，聪明的对手也想得到。要写清对手已经堵了哪几条、为什么堵不全（人手、时间、惯例、眼界），主角赢在对手堵不住的地方，不赢在对手没想到。
- **空间**：人在哪里，能不能看见、听见；东西放在哪儿，前后一致（箭洞在大门门柱，不在正堂门柱）。
- **能力与设定**：一个人一夜能干多少活，活多了就分给别人；死士年龄在 16～45 岁之间；技能不越界。
- **前后呼应**：伏笔、称呼、物件（漆盒在谁手里）、伤势、天气前后一致。
