# 核心设定

> 标记说明：
> - **【已定】** 作者给出的原始设定，不擅自改动
> - **【建议】** 补充提案，作者确认后改成【已定】
> - **【待定】** 需要作者拍板

## 一、作品定位

- **类型**：历史穿越 · 系统流 · 纯爽文
- **基调**：轻松、嘴欠、不憋屈。主角不苦大仇深，也不为争霸而争霸。
- **一句话卖点**：别人穿越想争霸，他只想看热闹。可他的人每天都在变多，多到整个大唐都坐不住了。

## 二、【已定】作者原始设定

1. 主角穿越到唐初，**李世民刚刚称帝**的时候。
2. 主角心态：**游戏人间**。
3. 外挂：每天可召唤死士。第 1 天 1 个，之后每天比前一天多 1 个（第 n 天召唤 n 个）。
4. 死士是**标准生化人**，与人类没有区别。
5. 每个死士**自带一项人类技能**。
6. 死士对主角**绝对忠诚**。

## 三、【建议】补充设定

### 3.1 开局时间

第 1 天 = **武德九年八月初九（甲子日，公元 626 年 9 月 4 日）**，也就是李世民在东宫显德殿即位当天。

理由：开局就是"新皇登基、大赦天下"。第 20～22 天正好撞上颉利可汗兵临渭水便桥，第一卷的高潮是现成的。

### 3.2 召唤规则

| 项目 | 建议 | 为什么 |
|---|---|---|
| 刷新 | 每日子时刷新额度，当天任意时刻召唤 | 简单好记 |
| 过期 | 当日额度当日有效，不召唤就作废 | 逼主角每天扩张，"养不养得起"成为持续压力，剧情自己会转起来 |
| 出现位置 | 主角身边十步之内 | 几千人凭空出现在长安城里怎么藏，是前期最好用的麻烦 |
| 出现形态 | 成年人（约 16～45 岁），男女、相貌随机；身穿当时的平民布衣，身无分文 | 不白送装备 |
| 语言常识 | 自带当时的通用语言和基本生活常识，清楚自己是主角的死士 | 召唤出来就能干活，不用写教学 |
| 技能 | 每人一项，**从古今中外所有人类技能里随机抽**，水平是该行当的顶尖（宗师级） | 每天"开盲盒"就是天然的爽点节奏。现代技能（外科、化工、冶金）撑起种田升级，奇葩技能（电竞、直播带货、广场舞领舞）负责笑点 |
| 身体 | 普通健康人类：要吃饭睡觉，会受伤、生病、衰老、死亡；死了不能复活 | 死士不是无限血量的消耗品，打仗才有分量 |
| 忠诚 | 绝对忠诚，不可能被策反；但有独立思考和个性，不是木偶 | 能写出性格各异的配角 |
| 管理 | 主角有一份只有自己看得见的"名册"，能查看所有死士的编号、技能、存活状态；**没有**心灵感应 | 方便写"翻名册找人"的桥段；传令仍然要靠人，保留信息差 |

### 3.3 主角

- **姓名**：沈游（暂定，可换）
- **穿越前**：现代互联网公司的后端程序员，加班到凌晨三点，趴在工位上睡着，醒来就到了唐朝。历史知识是爱好者水平：知道大事件和名人，记不清细节。这样他"大概知道要发生什么，但总有意外"。
- **穿越赠品**：听得懂、也说得出当时的语言。除此之外什么都没有。
- **性格**：游戏人间。做事只看"好不好玩"；嘴欠，心不坏；有底线：不滥杀无辜，不欺负平头百姓。
- **志向**：**不想当皇帝**。五更上朝、批奏折、跟魏征吵架，跟上班没区别。他要的是在大唐过得最舒服、看最大的热闹。这是本书和一般争霸文最大的区别。
- **称呼**：死士们管他叫"老板"（当了七年牛马，终于当上老板的执念）。唐人听不懂这两个字，久而久之成了内部暗号。

### 3.4 死士命名

前期主角亲自起名。第一个叫"周一"，理由是"一个礼拜里最难熬的一天，你是第一个，以后最辛苦"。人一多就起不过来了，改用编号加外号。"起名是天下第一难事"可以当长期梗。

**粮食参照**：唐制丁男日给米二升，一人一年约七石。一万人一年就是七万石。贞观元年关中饥荒，"米斗值绢一匹"。**吃饭会是第二卷的头号难题。**

**节奏提示**：
- 前一百天（五千人以内）是"小团伙"阶段，写个人和小队的骚操作；
- 一年后（六万多）是"地下势力"阶段，开始跟朝廷较劲；
- 三年后（六十万）在数量上已经是另一个大唐，舞台必须扩到塞外和海外。

## 五、天然的矛盾引擎

爽文也需要摩擦。摩擦是燃料，不是憋屈。

1. **吃饭**：人数平方级增长，唐初偏偏缺粮。
2. **身份**：户籍、过所、坊市、宵禁，几千个"黑户"往哪儿藏？
3. **藏不住**：人多到一定程度，朝廷一定会察觉。对手是李世民、长孙无忌，以及可以改造成"暗线追查力量"的百骑。
4. **抽卡随机**：想要铁匠，来了个厨子；计划赶不上开箱。（对主角是随机，作者心里要有数：关键剧情要用的技能，提前几天抽出来埋好。）
5. **死士是人**：会死、会受伤，不能无脑填命。
