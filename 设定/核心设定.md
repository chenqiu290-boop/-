# 核心设定

> 标记说明：
> - **【已定】** 作者给出的原始设定，不擅自改动
> - **【建议】** 补充提案，作者确认后改成【已定】
> - **【待定】** 需要作者拍板

## 一、作品定位

- **类型**：历史穿越 · 系统流 · 纯爽文
- **基调**：轻松、嘴欠、不憋屈。主角不苦大仇深，也不为争霸而争霸。
- **一句话卖点**：别人穿越想争霸，他只想看热闹。可他的人每天都在变多，多到整个大唐都坐不住了。

## 二、【已定】作者原始设定

1. 主角穿越到唐初，**李世民刚刚称帝**的时候。
2. 主角心态：**游戏人间**。
3. 外挂：每天可召唤死士。第 1 天 1 个，之后每天比前一天多 1 个（第 n 天召唤 n 个）。
4. 死士是**标准生化人**，与人类没有区别。
5. 每个死士**自带一项人类技能**。
6. 死士对主角**绝对忠诚**。
7. 死士的技能**完全随机**。
8. 死士**可以结婚生子**。
9. 外挂**暂时不升级**。
10. 主角有感情线（作者第17章前改定）：走世家女一线，慢热，在铺垫章里推进，详见 `设定/写作规范.md` 零点九与 `大纲/第一卷细纲.md` 感情线一节。
11. 主角会买女性奴婢来提高生活质量，体现唐朝特色。
12. 当日召唤额度**过期作废**，不能存。
13. 死士**知道自己是被召唤出来的**，但觉得无所谓。
14. 主角**不当皇帝**。
15. 对话鲜活、欢快，但**不犯傻**。
16. 主角骨子里**不怕**：只要稳住，天下早晚是他的。
17. 称呼**按唐朝习惯**。
18. 所有配角**不降智**：有自己的想法、立场，做事讲逻辑。

> 15～18 的细则见《写作规范》。

## 三、【建议】补充设定

### 3.1 开局时间

第 1 天 = **武德九年八月初九（甲子日，公元 626 年 9 月 4 日）**，也就是李世民在东宫显德殿即位当天。

理由：开局就是"新皇登基、大赦天下"。第 20～22 天正好撞上颉利可汗兵临渭水便桥，第一卷的高潮是现成的。

### 3.2 召唤规则

| 项目 | 建议 | 为什么 |
|---|---|---|
| 刷新 | 每日子时刷新额度，当天任意时刻召唤 | 简单好记 |
| 过期 | **【已定】** 当日额度当日有效，不召唤就作废 | 逼主角每天扩张，"养不养得起"成为持续压力，剧情自己会转起来 |
| 出现位置 | 主角身边十步之内 | 几千人凭空出现在长安城里怎么藏，是前期最好用的麻烦 |
| 出现形态 | 成年人（约 16～45 岁），男女、相貌随机；身穿当时的平民布衣，身无分文 | 不白送装备 |
| 语言常识 | 自带当时的通用语言和基本生活常识，清楚自己是主角的死士 | 召唤出来就能干活，不用写教学 |
| 来历 | **【已定】** 知道自己是被召唤出来的，但无所谓。写法：像对待"出生地"一样淡定，"人都不记得自己怎么生下来的，我好歹知道"；唐人问"你打哪儿来"，答"郎君那儿来的" | 省掉身份认同的苦情戏，保持轻松基调 |
| 技能 | 每人一项，**【已定】完全随机**，从古今中外所有人类技能里抽；水平是该行当的顶尖（宗师级） | 每天"开盲盒"就是天然的爽点节奏。现代技能（外科、化工、冶金）撑起种田升级，奇葩技能（电竞、直播带货、广场舞领舞）负责笑点 |
| 身体 | 普通健康人类：要吃饭睡觉，会受伤、生病、衰老、死亡；死了不能复活 | 死士不是无限血量的消耗品，打仗才有分量 |
| 忠诚 | 绝对忠诚，不可能被策反；但有独立思考和个性，不是木偶 | 能写出性格各异的配角 |
| 管理 | 主角有一份只有自己看得见的"名册"，能查看所有死士的编号、技能、存活状态；**没有**心灵感应 | 方便写"翻名册找人"的桥段；传令仍然要靠人，保留信息差 |

### 3.3 主角

- **姓名**：沈游（暂定，可换）
- **穿越前**：现代互联网公司的后端程序员，加班到凌晨三点，趴在工位上睡着，醒来就到了唐朝。历史知识是爱好者水平：知道大事件和名人，记不清细节。这样他"大概知道要发生什么，但总有意外"。
- **穿越赠品**：听得懂、也说得出当时的语言。除此之外什么都没有。
- **性格**：游戏人间。做事只看"好不好玩"；嘴欠，心不坏；有底线：不滥杀无辜，不欺负平头百姓。
- **志向**：**【已定】不当皇帝**。五更上朝、批奏折、跟魏征吵架，跟上班没区别。他要的是在大唐过得最舒服、看最大的热闹。这是本书和一般争霸文最大的区别。
- **【已定】骨子里不怕**：外挂只要求他活着，只要稳住，天下早晚是他的。所以他面对谁都从容，避开麻烦是"犯不着"，不是怕。
- **【已定】称呼**：按唐朝习惯。死士、奴婢称他"郎君"，外人称"沈郎"。详见《写作规范》。

### 3.4 死士命名

前期主角亲自起名，按"周一、周二、周三……"排（第八天起改由周一按百家姓派名，见 3.8）。唐人听来就是周家排行老大、老二、老三，很自然；名字里藏着"星期几"，是主角自己的暗梗（第一个叫周一，因为"一个礼拜里最难熬的一天，第一个往后最辛苦"）。一个礼拜排完换个姓接着排（第二周姓郑），人多了改用编号加外号。

**【已定·第17–19章后】死士与已有人物重名的处理：**死士照百家姓顺序派名，每姓七人；遇到与已有的非死士人物同名（如刺客韦三、裴家门客柳七），死士跳过那个编号，顺延多取一个编号补满七人（例：韦姓死士为韦一、二、四、五、六、七、八；柳姓为柳一至柳六、柳八）。已写进正文的名字不改。葛四等被召唤出的人，按死士计入人数。

### 3.5 死士婚育

- **【已定】** 死士可以结婚生子。
- **【建议】** 后代是普通人：不自带技能，不受系统约束，也不进名册。但他们在主角的势力里长大，天然亲近。
- **【建议】** 死士可以和死士成婚，也可以娶唐人、嫁唐人、入赘唐人家。和唐人成婚是给死士"洗白"户籍的捷径。
- **历史助攻**：贞观元年二月，太宗下诏劝婚：男二十、女十五以上还没成家的，以及丧偶守制期满的，州县都要督促婚配；户口增加还算地方官的政绩。死士成婚正好顺着朝廷的风向走，地方官巴不得。
- **长线**：十几年后会出现"死士二代"。到第六卷出海时，他们就是海外据点的本地人口。

### 3.6 奴婢（唐朝特色生活）

- **【已定】** 主角感情线走世家女（原“无感情线”已废）；会买女性奴婢，提高生活质量。
- **和死士的分工**：死士是"员工"，忙生意和正事；奴婢管日常起居：煎茶、梳头、熏香、洗衣做饭、弹琵琶唱曲。
- **唐代奴婢常识**（写作参考）：
  - 长安西市有"口马行"，奴婢和牲口在同一个行当里买卖。
  - 买卖必须立"市券"，到官府登记，不立券要挨笞。主角又一回拿周一伪造的身份过官面（头一回是第五章附籍、立宅契）。
  - 来源：罪没官的奴婢（玄武门之后，东宫、齐王府的人有一部分流落出来）、战俘、胡商贩来的西域胡女等。
  - 唐律把奴婢算作"贱民"，主人可以买卖，但不能私自杀死；主人写一份"放书"就能放良。
  - 新罗婢、胡姬当垆这类风物多见于盛唐以后，武德末年可以有，但不宜多。
- **【建议】主角的规矩**：好吃好喝、给月钱、不打骂。他成了长安出了名的"好东家"，口马行里的奴婢都盼着被他买走。嘴欠心不坏，这也是"爽"的一部分。
- **【建议】身边唯一的外人**：奴婢是主角身边唯一**不受系统约束**的人，她们的忠诚靠待遇换来，不是天生的。这留了一个口子：后期百骑想往他府里安插眼线，只能从奴婢下手。
- **第一批（第七章）**，与主角均无感情戏：
  - **青萝**，十九岁，原齐王府侍女（没官发卖）：高挑白净，眉如淡墨，举止是王府里练出来的；识字、会煎茶、梳头、熏香；心思深，先试探再交心；知道不少权贵内情，是个现成的情报钩子。
  - **阿娜**，二十岁，粟特米国人：栗色卷发、琥珀色眼睛、蜜色皮肤，个子高；弹胡琵琶、跳胡舞；爱笑，想家，汉话说不利索。
  - **阿杏**，十八岁，关中人，家生婢（主家分家被卖）：圆脸酒窝，晒成小麦色，结实能干；洗衣做饭样样会；嘴快，长安城里的八卦都从她这儿来。

### 3.7 唐风生活清单

主角"游戏人间"的消遣素材，也是生意素材：

- **吃**：胡饼、毕罗、汤饼、鲙（生鱼片，唐人很爱吃）；煎茶要加盐加姜，主角喝不惯，改喝清茶。
- **玩**：马球（击鞠）、斗鸡、樗蒲、双陆、蹴鞠、围棋。
- **游**：曲江、乐游原、终南山。
- **酒**：唐初多是米酒、浊酒，度数低；葡萄酒稀罕，太宗要到贞观十四年破高昌后才得到马乳葡萄和酿法。高度酒、葡萄酒又是一门生意。

### 3.8 势力结构【已定方向】

人越来越多，不围在主角身边，而是散出去做事、赚钱、发展势力。主角只听汇报、拍板，然后享受。

- **内宅**：护院队（周四领头，刀术、骑射、弩机等武力死士）、婢女、厨房，负责主角的安全和起居。
- **总管**：周一，大管家，统管名册和各摊人事；郑三，总账房。
- **外务**（第九章起陆续铺开，每摊一个死士领头）：
  - 糖坊（陈一）：白糖，经窦十一郎卖进长安权贵和宫里，经康萨陀卖往西市、西域。
  - 酒坊（冯二）：先酿好酒，再出蒸馏的烈酒。
  - 点心铺（陈二）：开在东市，白糖点心，是沈家在明面上的门脸。
  - 说书（冯四）：在东西两市的酒肆、寺院俗讲里说书，聚人气、听消息、造舆论。
  - 夜里的眼睛（冯五追踪、周日口技、陈六攀援）：盯钱彪、裴家、"贵人"，是情报网的起点。
  - 商路（郑一跟着康萨陀的驼队）：学西域的路子，打听突厥动静。
  - 营造（周五、郑二、陈三等）：翻修宅院、扩建、给各摊盖作坊。
- **名册**：第八天起，主角不再一个个起名。周一照着百家姓一周换一个姓往下派（周、郑、冯、陈、褚、卫……），平时多用外号（"糖陈""酒冯"）。
- **宅院升级路线**：开明坊东北角凶宅（翻修成享乐之所，买下周边空地扩建）→ 城南的园林大宅 → 终南山别业 → ……
- **营缮令**：唐律限制庶人堂屋的间架规格，但管不了屋里铺什么、园子里种什么。主角在规矩之内把日子过到最舒服。

## 五、天然的矛盾引擎

爽文也需要摩擦。摩擦是燃料，不是憋屈。

1. **吃饭**：人数平方级增长，唐初偏偏缺粮。
2. **身份**：户籍、过所、坊市、宵禁，几千个"黑户"往哪儿藏？
3. **藏不住**：人多到一定程度，朝廷一定会察觉。对手是李世民、长孙无忌，以及可以改造成"暗线追查力量"的百骑。
4. **抽卡随机**：想要铁匠，来了个厨子；计划赶不上开箱。（对主角是随机，作者心里要有数：关键剧情要用的技能，提前几天抽出来埋好。）
5. **死士是人**：会死、会受伤，不能无脑填命。
6. **身边唯一的外人**：奴婢不受系统约束，忠诚得靠待遇换。

### 7.4 编制原则

1. **按技能分门，按差事分队，十人一火。** 一队三五十人为宜，过五十就"分家"（见 7.6 第 8 条）。火长管十个人，队长管几个火长，沈游只认十八个队长和周一、郑三。褚一的话：府兵本来就是十人一火。
2. **一人一队，可兼不可挂。** 名册上只记本队；兼的差要两边队长都知道。夜袭那种"惊马、取货、断后"是战时编组，褚一点名临时抽人，打完各回本队。
3. **每队必有副。** 队长出事、出远门，副当场接手；队长和副不同时离开驻地。名册副本、账副本各藏一处（"狡兔三窟"）。
4. **人散在各摊，每摊有真营生。** 每一摊的人数不超过那个行当常见的规模：糖坊几十个伙计说得过去，一座宅子一百个家丁就说不过去。外人只看得见一摊一摊，加不起来。新人不在一处堆着，三日后就散进各摊（见 7.6）。
5. **知数分级。** 火长知本火，队长知本队；全数只有三个人心里有：沈游（金字名册）、周一（名册）、郑三（从粮和钱能倒推）。内宅知道得最少——婢女是外人，忠诚靠待遇换（3.6），内宅的人不碰名册，名册不在内宅过夜。阿史那这类雇来的人、婢女，都不入编，可以跟着某队办差，不看名册。
6. **粮和钱分队走。** 郑三每旬按队发粮帖、钱帖，各队就近买粮、领窖粮，不在一家粮行大宗进货。外人从一处买卖看不出总数。**但聪明人照样能估个大概**：窦十一郎靠窖、康萨陀靠胡饼笼数、吴管家靠灯和门房，整编只让他们估不准、估不全，不会让他们估不出（配角不降智）。
7. **管钱的不做买卖，做买卖的不管钱。** 郑三不兼懋迁；各队记"日簿"，十日交簿房一次，郑三对账。
8. **消息往上走，帮手横着借。** 候望、弦歌的消息汇到周一，再到沈游；队与队之间可以直接搭手，但要调人得写"缺人帖"给簿房。
9. **兵器守法，人不扎堆。** 横刀、弓箭可以明着有；弩、甲、矛槊是禁兵器（《擅兴律》私有禁兵器有罪，弩、甲论罪更重），冯六的弩只在宅里和野外用，不进坊市；干城平时不在一处聚过三五十人。冯七的晨练对外说是"东家的规矩，早起活动筋骨"；有外人在的场合要"踩乱"（第十八章回乡府兵队正已看出"走得太齐"）。
10. **死士不是应声虫。** 编排草案先给队长看，谁觉得放错了当面说；队名由队长自己起；谁觉得自己放错了地方，自己去找周一。沈游最后拍板。
11. **人要放对地方。** 整编最直接的好处是把放错的人挪回去（例：烧炭宗师姜五在灶房劈了三个礼拜柴，糖坊的骨炭却一直不够），这是正文里让读者看见"整编有用"的抓手。
12. **不写缺钱。** 编制的压力只来自人数平方级增长：住处、口粮、冬衣、过所、马场，一样比一样大。

### 7.5 沈游本人的态度与做法

- **为什么做**：他要的是"躺着也知道家里怎么样"。整编不是为了管人，是为了省心。几百人还能靠周一一个脑子记，几千人不行；周一一病，全家抓瞎。
- **怎么做**：只见队长；每旬一次"旬报"，门房按帙号排时辰，一队一刻；平日只看金字名册的"存活"一栏（3.2：编号、技能、存活状态，只有他看得见，谁也偷不走、改不了）。派头因此往上走一格：从一个个点名，到只见十八个队长，他自己话更少，敲一下扶手就算定了。
- **现代思路、唐人说法**（嘴上只说右栏，心里可以吐槽左栏）：

| 他心里想的 | 嘴上说的 / 唐人听来 |
|---|---|
| 组织架构图 | 拿纸画一棵树。周一："这不是谱牒么？""对，咱家的谱" |
| 权限分级 | "各人只知道自己那一摊" |
| 备份 / 容灾 | "底子留两份，放两处""每队有个副""狡兔三窟" |
| 单点故障 | "周一一病，全家抓瞎" |
| 日志 | "日簿，十日一交" |
| 工单 / 需求单 | "缺人帖" |
| 定时汇报 | "旬报" |
| 扩容拆分 | "人过五十就分家" |
| 编号 / 命名空间 | 千字文帙号（7.7） |
| 定期换密钥 | "帙号一季一换" |
| 只读主库 | 金字名册（只他一人看得见） |

- **他不做的**：不一个个亲点；不开大会（五百人站一院子，等于请人来数人头）；不搞繁文缛节；不把冷门技能的人当闲人，掏耳朵的也得有体面差事；不替队长起名（只挑了"解烦"一个，最得意）。
- **活人感的抓手**：翻金字名册翻到眼花（"比翻五百条聊天记录还累"）；想起名"一组二组"被周一当场否掉；画谱画得歪；记不住名字就偷看金字；认真时手上忽然静下来。

### 7.6 新召唤死士的归队规则

1. **召唤（硬规则，不变）**：子时，东院北头毡帐（第十七章）或出行时飞刍扛的帐子；清场，帐里只沈游一人；簿房值夜的人（周一或孔三）在布障外，声响之后才掀帐。新人出现那一刻，任何人不得看见。
2. **登记**：周一照百家姓派名，每姓七人，跳过吴、王、沈，重名跳号（3.4）；问本事、记名册。次日沈游对一遍金字名册，技能以金字为准（两份对账）。
3. **新附三日**：新人先进"新附棚"（在家是东院，在外是随行营地），三日内郑三发衣粮，周一办过所（暂挂某摊雇工、某驼队脚力），冯七教步子，周六看一眼身子。"新附"是附籍用语（第五章"还俗僧，新附"），唐人听来不怪。
4. **按技能归门**：打斗、射、追踪、行军 → 干城；手艺制作 → 百工；出产、买卖、农牧、娱乐 → 货殖；起居、医药 → 内宅；文书、算账 → 簿房。
5. **按缺口归队**：各队的"缺人帖"优先；同等情况先补眼下最缺的。第二卷开头的顺序建议：牧圉（上千匹马）> 仓廪（粮）> 绳墨（盖房）> 飞刍（运）> 其余。
6. **冷门技能**：一时没处放的，先挂簿房"闲册"，但不养闲人，跟飞刍、仓廪干搬运、守窖、赶车之类的活；三十天内周一给个去处，或者立新队。娱乐类先进弦歌，侍奉类先进兰汤（"这两队专收奇怪的人"，日后反倒是权贵圈里最灵的耳朵）。
7. **立新队**：同类技能凑够三人、又有活干，就立队；队长起名，周一把关，帙号顺延。
8. **分队**：一队过五十人就分家，副升任新队队长，原队再补一个副；新队另起名。
9. **战时编组**：褚一点名抽人；解烦近身番不抽（周四不离十步）。
10. **外人不入编**：阿史那、婢女、雇来的唐人，不进名册。
