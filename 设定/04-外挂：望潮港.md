# 外挂：望潮港

## 一句话

**主角随身带着一座无人的现代超大型货运港口。港里时间静止，几十万个集装箱，几乎什么都有，但箱子全封着、没有标签、没有电，想要什么得自己一箱一箱去翻。摸得到的东西就能带出来，可带出来的再也放不回去。**

这个外挂和主角的职业是咬合的：别人拿到一座港口只会瞎翻；他干了十年仓储，懂箱号、懂箱型、懂唛头、懂舱单，**他翻得比谁都快，也比谁都会管**。

---

## 一、港口是什么

- **名字**：望潮港（虚构），是主角所在物流公司的合作港口。穿越前三天，他就在这里的驻港仓库加班盘点。
- **状态**：定格在他穿越的那一刻。天是阴沉沉的白昼，海面不动，旗子不飘，**一个人都没有**。
- **时间静止**：港里的一切都不会变。冷库里的肉永远是冻的，土豆永远不发芽，药永远在有效期内，汽水打开了还是冒泡的。**东西一旦带出港，就开始正常老化、腐坏。**
- **没有电**。岸桥、龙门吊都停着，电脑开不了机。几台柴油叉车、正面吊和备用发电机可以手动启动，油箱里的柴油就是全部。

### 港区布局

| 区域 | 内容 | 用处 |
|---|---|---|
| **集装箱堆场** | 几十万个箱子，日用品、五金工具、服装、电子、家具、机械零件、化肥、药品、种子……完全随机 | "翻找"的主战场 |
| **冷藏箱区** | 肉、海鲜、水果、鲜土豆、需要冷链的药品 | 时间静止，全都新鲜如初 |
| **散货码头** | 粮食筒仓（进口玉米、大豆、小麦），铁矿石、煤炭堆场 | 种田线的重头 |
| **港区生活区** | 办公楼、档案室（纸质舱单、提单）、食堂、便利店、员工宿舍 | 档案室是港口的"索引"，找到之后翻找效率大增；宿舍和便利店里有书 |
| **港史陈列馆** | 港口自己的展厅，有"海上丝绸之路"展板和中国历代大事年表 | **查历史的地方之一** |
| **危险品堆场** | 化工原料（烧碱、硫酸等）、烟花爆竹、电池 | 制皂、开山、信号 |
| **泊位巨轮** | 一艘靠港的集装箱船，驾驶台上有海图、罗盘、六分仪 | 卷六海贸的钥匙 |

港区占地十几平方公里，光是从堆场一头走到另一头，就要大半个时辰。**他知道港里有什么，但不知道东西在哪儿。**

## 二、规则

### 1. 进港、出港

- 闭眼凝神，或者入睡时，他可以选择"进港"。**进去的是意识**，用的是他现代的身体；唐朝那边的身体留在原地，像睡着了一样。
- 睁眼就能出港。
- 外面的身体被摇晃、被烫、被疼痛或巨响惊动，会把他直接拽出港。比如阿蕖哭着喊"阿耶醒醒"，他在港里会听见，像是从很远的地方传来的。
- 【按我的理解】"时停"指港里的东西静止不变，**外面的时间照常流逝**：他在港里翻一夜，外面也过了一夜，醒来时像熬了一个通宵。如果你想要"在港里待多久，外面都不过时间"，告诉我，规则可以改。

### 2. 带东西出来

- 出港的那一刻，他**手里拿着的、身上背着的、身体直接接触到的**可移动物品，都会跟他一起出来，出现在他唐朝身体的身边。
- 拿得动的能带，拿不动的只要摸着也能带：一只手按在集装箱上出港，整个集装箱都会出来。

**三条补充规则，用来堵漏洞**
- **只算直接接触，不算连锁。** 摸着最底下的箱子，压在上面的五层不会跟着出来；摸着一个箱子，挨着它的箱子也不会出来。
- **固定在港口上的东西带不走。** 地面、建筑、岸桥、筒仓本身都不行，里面装的货可以。
- **外面得有地方放。** 东西出现在他身体周围。他要是躺在自家床榻上摸着集装箱出港，房子就塌了。所以大件只能去旷野、河滩上取。

### 3. 放不回去

**只出不进。** 唐朝的东西放不进港，从港里拿出来的东西也放不回去。

所以港口不能当仓库，不能藏东西，也不能用来瞬间运货。一个集装箱拿出来了，就得在唐朝想办法藏它、拆它、运它。

### 4. 查历史

港里能查历史，但**只有大事，没有细节**：
- 港史陈列馆的大事年表和"海上丝绸之路"展板；
- 员工宿舍里的中学历史课本、一两本通俗历史读物；
- 便利店书架上的杂志和儿童历史绘本。

这些东西能告诉他"哪一年谁当了皇帝、哪一年打了哪一仗、谁赢了"，**不会告诉他哪天、在哪儿、谁说了什么**。主角自己也一样，他是历史爱好者，大事记得，细节记不住。

所以主角的"先知"是这样用的：**大事靠记忆和港里的书，细节靠推理。** 比如他记得"李世民打回了河东"，再亲眼看见裴寂把河东的粮全烧了，就能推出"唐军过来以后一定缺粮"。这比照着史书抄答案好看，也更显人物的脑子。

## 三、限制（为什么不会太无敌）

| 限制 | 说明 |
|---|---|
| **翻找本身就难** | 几十万个箱子，没有标签、没有电、没有人帮忙。一个人翻一辈子也翻不完。想要的东西，可能在十公里外的某一层某一箱 |
| **东西有限，用一件少一件** | 港口不会补货。真正的财富，是**照着样品让大唐的工匠造出来**，是把一筐种子种成一片庄稼 |
| **出了港就会坏** | 时间静止只在港里有效。药带出来就开始过期，种子带出来就开始失去活力 |
| **没有军火** | 这是民用港口，枪炮不走这里。危险品区的东西，主角自己有分寸，只用来开山、发信号、制皂 |
| **大件用不了** | 卡车、拖拉机、工程机械能带出来，但唐朝没有柴油、没有配件、没有公路。带出来就是一堆铁 |
| **来历是麻烦** | 塑料、不锈钢、印刷标签，在唐朝都是"妖物"。每样东西都得去掉标签、换掉包装，对外说是"海外胡商的奇货"。被人识破，轻则被抢，重则以妖言论罪 |
| **耗时间、耗精神** | 在港里翻一夜，就等于一夜没睡 |

## 四、翻找怎么写才好看

1. **开箱是固定爽点。** 每次开箱都像拆盲盒：一箱拖鞋、一箱圣诞彩灯是"空军"，一箱钢锯、一箱化肥就是"大奖"。读者会跟着期待。
2. **职业知识就是翻找技巧。** 冷藏箱一定带制冷机组；罐箱装液体；开顶箱多半装钢材、石料；箱门上的唛头写着发货地和收货人，看得懂就能猜货。他越翻越准，找到档案室以后更是如虎添翼。
3. **港口给的是火种，烧起来靠他。** 一把钢锯，让铁匠周铁头琢磨三个月，大唐就有了好锯；一筐土豆种下去，三年后就是一县的口粮。这守住了全书"靠后勤、靠组织"的卖点。
4. **港口是一个人的孤独。** 偌大的港区只有他一个人。他偶尔会坐在便利店门口的台阶上，开一罐可乐，看着不动的海发呆，想他现代的爸妈。这是写细腻情感的地方，别省。
