# 外挂：望潮港

## 一句话

**主角随身带着一座无人的现代超大型货运港口。他一进港，外面的时间就停了；在里面待一天、一个月，出来时外面仍是同一瞬间。港里几十万个集装箱，几乎什么都有（热武器除外），但箱子全封着、没有标签、没有电，想要什么得自己一箱一箱去翻。摸得到的东西就能带出来，可带出来的再也放不回去。**

这个外挂和主角的职业是咬合的：别人拿到一座港口只会瞎翻；他干了十年仓储，懂箱号、懂箱型、懂唛头、懂舱单，**他翻得比谁都快，也比谁都会管**。

---

## 一、港口是什么

- **名字**：望潮港（虚构），是主角所在物流公司的合作港口。穿越前三天，他就在这里的驻港仓库加班盘点。
- **状态**：定格在一个阴天的傍晚，正是他穿越前那天下班离开港口的时候。天色灰白，像是随时要下雨，又永远不会下。海面不动，旗子不飘，海鸥停在半空，**一个人都没有**。
- **港里的东西不会变**：冷库里的肉永远是冻的，土豆永远不发芽，药永远在有效期内，汽水打开了还是冒泡的。**东西一旦带出港，就开始正常老化、腐坏。**
- **没有电网**。岸桥、龙门吊都停着。几台柴油叉车、正面吊和备用发电机可以手动启动，油箱和油罐里的柴油就是全部。充电宝、电池都是满电的。

### 港区布局

| 区域 | 内容 | 用处 |
|---|---|---|
| **集装箱堆场** | 几十万个箱子，日用品、五金工具、服装、电子、家具、机械零件、化肥、药品、种子、运动器材……完全随机 | "翻找"的主战场 |
| **冷藏箱区** | 肉、海鲜、水果、鲜土豆、需要冷链的药品 | 全都新鲜如初 |
| **散货码头** | 粮食筒仓（进口玉米、大豆、小麦），铁矿石、煤炭堆场 | 种田线的重头 |
| **港区生活区** | 办公楼、档案室（纸质舱单、提单）、食堂、便利店、员工宿舍 | 档案室是港口的"索引"；他在港里吃、住都在这儿 |
| **港口公安、安保室** | 防刺服、防割手套、头盔、防暴盾牌、钢叉、警棍、强光手电、对讲机、手铐 | **保命装备的第一个来源** |
| **医务室、应急物资库** | 急救包、止血带、缝合包、抗生素、退烧药、碘伏、担架、防烟面罩、消防服、救生衣、安全绳 | **保命装备的第二个来源** |
| **港史陈列馆** | "海上丝绸之路"展板，中国历代大事年表 | 查历史 |
| **危险品堆场** | 化工原料（烧碱、硫酸等）、烟花爆竹、电池 | 制皂、开山、信号；**必要时是隐蔽的杀招** |
| **泊位巨轮** | 一艘靠港的集装箱船，驾驶台上有海图、罗盘、六分仪 | 卷六海贸的钥匙 |

港区占地十几平方公里，光是从堆场一头走到另一头，就要大半个时辰。**他知道港里有什么，但不知道东西在哪儿。**

## 二、规则

### 1. 进港、出港

- **只要是清醒的**，他闭眼一念，**整个人**连同身上穿戴的东西就进了港。睡着、昏迷时进不去。
- 他一进港，**外面的时间就完全停止**。
- 出港时，他回到**进港时的原地、同一瞬间**。在旁人眼里，他连眼皮都没多眨一下。
- **他自己的时间照常走**：在港里会饿、会累、会困，伤口会流血，也会慢慢愈合。在港里过的日子都是真日子，**待久了，人也会老**。好在港里吃的、睡的、药都管够。
- 活人、活物都带不进港。全世界只有他一个人能进去。

### 2. 带东西出来

- 出港的那一刻，他身上穿戴的、手里拿着的、身体直接接触到的可移动物品，都会跟他一起出来：
  - **穿在身上的，出来还在身上**；
  - **拿在手里的，出来还在手里**；
  - **摸着的大件，出现在他身边。** 一只手按在集装箱上出港，整个集装箱都会出来。

**三条补充规则，用来堵漏洞**
- **只算直接接触，不算连锁。** 摸着最底下的箱子，压在上面的五层不会跟着出来；摸着一个箱子，挨着它的箱子也不会出来。
- **固定在港口上的东西带不走。** 地面、建筑、岸桥、筒仓本身都不行，里面装的货可以。
- **外面得有地方放。** 大件出现在他身体周围。他要是在自家屋里摸着集装箱出港，房子就塌了。所以大件只能去旷野、河滩上取。

### 3. 放不回去

**港口只出不进。** 唐朝的任何东西都留不在港里，从港里拿出去的东西也留不回去。

- 他身上穿戴的东西会跟他进港，但**出港时一定跟他出来**，放下了也会跟回去。比如他穿着从港里拿出去的防刺服进港，脱在宿舍里，出港时它还是会出现在他身上。
- 所以港口不能当仓库，不能藏东西，也不能用来运货。一个集装箱拿出来了，就得在唐朝想办法藏它、拆它、运它。

### 4. 查历史

港里能查历史，但**只有大事，没有细节**：
- 港史陈列馆的大事年表和"海上丝绸之路"展板；
- 员工宿舍里的中学历史课本、一两本通俗历史读物；
- 便利店书架上的杂志和儿童历史绘本。

这些东西能告诉他"哪一年谁当了皇帝、哪一年打了哪一仗、谁赢了"，**不会告诉他哪天、在哪儿、谁说了什么**。主角自己也一样，他是历史爱好者，大事记得，细节记不住。

所以主角的"先知"是这样用的：**大事靠记忆和港里的书，细节靠推理。** 比如他记得"李世民打回了河东"，再亲眼看见裴寂把河东的粮全烧了，就能推出"唐军过来以后一定缺粮"。

### 5. 来历：能说的、能半说的、只能自己用的

港里拿出来的东西，按"能不能见人"分三档：

| 档 | 例子 | 怎么处理 |
|---|---|---|
| **能公开** | 种子、工具样品、布匹、盐、糖，以及去掉标签、换了包装的日用品 | 对外说是"海外胡商的奇货""西域来的种子"，经得起一般人追问 |
| **能半公开** | 药品、强光手电、望远镜、钢锯 | 只给心腹用、只在心腹面前用，对外绝口不提 |
| **只能自己用** | 自己和阿蕖的吃喝、防刺服、防暴盾、报警器、电击器、扎带、危险品 | **说不清来历，也不打算说清**。贴身藏着，夜里用，用完收好、残渣清干净。被人撞见了，只能装傻、搪塞，或者让它变成"神迹""怪谈" |

> 第三档是最好写的地方：一个人守着一堆不能见光的东西，处处得小心，又处处能出奇制胜。

**黑货与白货**：主角自己的说法。港里的东西是"黑货"，要么自己用，要么"洗白"，也就是去标签、换包装，混进唐朝的货里慢慢放出去。唐朝本地的粟、绢、盐是"白货"，拿得出手，经得起问。所以他明明有一整个筒仓的进口粮，还是要藏村里那二十来石粟：那是白货，是将来拿去跟秦王府换信用的本钱。

## 三、人身安全：靠港里的东西保证

**设计目标：只要主角自己不犯糊涂，他就死不了。**

### 1. 危险来了：进港，时间停住

刀砍到面前、箭射过来、房子着了火，只要他看见了、意识到了，就能**一念进港**。外面的刀停在半空，他有的是时间：

- 想对策；
- 穿上防刺服、戴上头盔、拿起防暴盾牌；
- 带一件趁手的东西出去，比如钢叉、强光手电、防狼喷雾、电击器、灭火器、防烟面罩、安全绳。

然后回到同一瞬间，那一刀落下来，砍在盾上。

> 他回到的是**原地**，躲不开已经到眼前的东西，只能挡、只能扛。所以每一次都要写清楚：他在港里想了什么、选了什么、为什么这么选。这才是看点。

### 2. 受了伤：进港治疗

只要还清醒，他就能带着伤进港。在港里用医务室的东西止血、缝合、上药、吃抗生素，躺在宿舍里养上十天半个月，外面一瞬都没过。

> **代价是暴露**：前一刻还血流如注的人，下一刻伤口已经结痂了。所以伤好了也得继续缠着绷带、装着瘸腿，哪怕在亲近的人面前也得演。这个桥段又好笑又好用。

### 3. 没察觉的危险：靠平时的准备

他唯一的软肋，是**没察觉的危险**和**失去意识**：睡梦中被刺、被人下毒、黑暗里飞来的冷箭、一闷棍打晕。

这正好合他谨慎的性子。他平时就做足了准备：
- **贴身穿防刺服**，外面罩着唐朝的袍子；
- 卧房门窗上装**电池报警器**，有人摸进来就"嘀嘀"响（第一次响的时候，刺客吓得以为闹鬼）；
- 吃别人给的东西前，偷偷用**食品快检试纸**测一下；
- 枕边放着**强光手电**和**防狼喷雾**；
- 身边有信得过的护卫（石敢）。

> 读者会看到，他能活下来不是因为运气，是因为他事事比别人多想一步。这和"人不犯我，我不犯人"的性格是一体的：他不惹事，但他时刻准备着别人来惹他。

### 4. 反击：非常手段

**人不犯我，我不犯人；人若犯我，而且要我的命，那就别怪我不讲规矩。**

危险品堆场的烟花、化工品是可以伤人、杀人的。但这是**隐蔽的非常手段**，有几条铁律：

1. **不能让人把这件事和他联系起来。** 只在夜里、无人处、混乱中用，用完把残渣、包装处理干净。
2. **不用费心解释，时人自己会往鬼神上想。** 唐初还没有火药兵器，一声巨响、一团火光、一道白光，唐朝人想破脑袋也想不到是人干的，只会说是**天雷、天火、鬼神、天谴**。坏人家里"遭了雷劈"，满村都会说是报应。
3. **只对真正要他命、要他家人命的人用。** 这是他的底线，也是他和那些反派的区别。
4. **不量产，不建火器部队，不在战场上公开用。** 他不想把这种东西带进这个时代，这是他自己的分寸。

> 写法上，这类场面不用写得太技术。重点写他的盘算、现场的混乱，以及事后满村满城的鬼神流言，他站在人群里跟着点头说"老天开眼"。既爽，又有幽默感。

### 5. 外挂保不了的

- **他身边的人。** 阿蕖、柳七娘、石敢、李老栓，外挂一概不管。这才是故事真正的危险所在。
- 钱、名声、官位、产业、盟友。
- 他的秘密。东西拿出来一多，迟早有人起疑。

## 四、限制（为什么不会太无敌）

| 限制 | 说明 |
|---|---|
| **没有热武器** | 民用港口，枪炮不走这里。危险品区的东西可以伤人，但只能当隐蔽的非常手段，不能公开、不能量产（见"反击：非常手段"） |
| **翻找本身就难** | 几十万个箱子，没有标签、没有电、没有人帮忙。想要的东西，可能在十公里外的某一层某一箱 |
| **时间是他自己的** | 外面不过时间，可他自己的时间在过。港里待一年，他就老一岁。翻遍整座港口，可能要搭上半辈子 |
| **孤独** | 港里只有他一个人。待得越久，越像被全世界扔下了 |
| **东西有限，用一件少一件** | 港口不会补货。真正的财富，是**照着样品让大唐的工匠造出来**，是把一筐种子种成一片庄稼 |
| **出了港就会坏** | 药带出来就开始过期，种子带出来就开始失去活力 |
| **大件用不了** | 卡车、拖拉机、工程机械能带出来，但唐朝没有柴油、没有配件、没有公路。带出来就是一堆铁 |
| **来历是麻烦** | 塑料、不锈钢、印刷标签，在唐朝都是"妖物"。每样东西都得去掉标签、换掉包装，对外说是"海外胡商的奇货"。被人识破，轻则被抢，重则以妖言论罪 |
| **粮食不能大搬** | 主角和阿蕖自己吃喝管够，主角在港里吃，阿蕖的那份偷偷带出来，**主角本人永远不会缺吃的**。难的是给别人：筒仓里的粮食拿得出来，但几千石粮凭空出现，解释不了来历，私藏军粮在乱世是死罪；而且粮食只会出现在他身边，照样要靠人和牲口去运。**港里的粮主要用作种子和救命，养军队靠的还是他组织起来的粮道。** 这条是守住"后勤"主线的关键 |

## 五、翻找怎么写才好看

1. **开箱是固定爽点。** 每次开箱都像拆盲盒：一箱拖鞋、一箱圣诞彩灯是"空军"，一箱钢锯、一箱化肥就是"大奖"。读者会跟着期待。
2. **职业知识就是翻找技巧。** 冷藏箱一定带制冷机组；罐箱装液体；开顶箱多半装钢材、石料；箱门上的唛头写着发货地和收货人，看得懂就能猜货。他越翻越准，找到档案室以后更是如虎添翼。
3. **港口给的是火种，烧起来靠他。** 一把钢锯，让铁匠周铁头琢磨三个月，大唐就有了好锯；一筐土豆种下去，三年后就是一县的口粮。这守住了全书"靠后勤、靠组织"的卖点。
4. **港口是一个人的孤独。** 偌大的港区只有他一个人，海鸥停在半空，海浪凝成一道白边。他会坐在便利店门口的台阶上，开一罐可乐，看着不动的海发呆，想他现代的爸妈。他在港里待得越久，就越想快点回去见阿蕖。这是写细腻情感的地方，别省。
