## 约定

- 设定里的 **【已定】** 是作者拍板的，**【建议】** 等作者确认，**【待定】** 等作者决定。
- 新增或修改设定时，更新《核心设定》，并在文末"变更记录"里记一笔。
- Day 以武德九年八月初九为第 1 天，第 N 天累计死士 = N(N+1)/2。
