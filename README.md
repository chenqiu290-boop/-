# 《大唐：从龙门囤粮开始》（书名暂定）

> 备选书名：《贞观粮商》《河东一粒粟》《我在大唐搞后勤》

## 一句话简介

三十四岁的仓储主管韩霁，一觉醒来成了武德二年河东龙门县一个三十四岁的辽东老兵。官府正逼着百姓烧掉存粮，他却记得《资治通鉴》里的一句话：一个月后，秦王李世民将踏冰渡河，而他的大军会断粮。

## 写作约定

1. **爽点节奏**：每 3～5 章一个小爽点（打脸、赚钱、获得认可），每 15～20 章一个中高潮，每卷结尾一个大高潮。
2. **金手指边界**：主角是历史爱好者，不是工程师。他知道"有这个东西、大概怎么做"，具体工艺靠工匠反复试错。这样主角的发明更可信，也能带出配角。
3. **反派不降智**：豪强、门阀、东宫的人都有自己的算计，主角要靠信息差和执行力赢，而不是靠对方犯蠢。
4. **历史大势基本不变**：玄武门、渭水之盟、灭东突厥等大事照常发生，主角改变的是细节、个人命运和"本不该那么惨"的地方。
5. **考据标记**：设定里写着【待核】的内容，正式成稿前要再查一次。
