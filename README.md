# 《大唐：从龙门囤粮开始》（书名暂定）

> 备选书名：《贞观粮商》《河东一粒粟》《我在大唐搞后勤》

## 一句话简介

三十四岁的仓储主管韩霁，一觉醒来成了武德二年河东龙门县一个三十四岁的辽东老兵，还多了个九岁的闺女，和一座随身携带的现代货运港口。他只想关起门来过自己的小日子，可官府要烧他闺女过冬的口粮，族叔要吞他的地，乱世一样一样找上门来。

## 写作约定

0. **细腻，但不啰嗦**：写光线、气味、温度、手上的触感，写人物细微的表情和停顿。但细腻靠的是**挑对细节**，不是堆细节：
   - **每章 3000～4000 字**，一章只写一两个场景，写不下就拆章。
   - **一个意思只说一遍**：不复述读者刚看过的内容，不解释笑点，不用"一遍，又一遍，又一遍"这类叠句凑气势。
   - **每个场景挑一两个最有分量的细节写透**，其余一笔带过。
   - **单句成段要省着用**，只留给真正的转折和章末钩子，一章十来处就够。
   - **心理活动点到为止**：推理只写关键一步和结论，不写全过程。
   - **吐槽一处一句**，不连着抖好几个包袱。

1. **爽点节奏**：**每章至少一个爽点**（打脸、反杀、开箱、赚钱、被认可、反派吃瘪），每 15～20 章一个中高潮，每卷结尾一个大高潮。就算是"抑"的章节，也要让反派当场吃一点亏。
   - **主角有港口兜底，心态要稳**：吃穿不愁，人身安全有保障，只要自己不犯病就不会落到绝境。他的难处只有两种：身边的人会受伤，港里的东西会暴露。不要写成卑微求生。

1.4. **外挂要常用、用得巧**：每章至少一处用港里的东西帮主角占上风，可以是**信息**（测量、望远镜、地图）、**效率**（工具碾压）、**安全**（防护、救命）、**人情**（救人、雪中送炭），也可以是**打脸**。用法比东西本身重要：时停里从容挑选、对外一句"胡商的"糊弄过去、唐朝人看得目瞪口呆，这些都是爽点。

1.5. **对话要活**：
   - 口语化，有来有回，有打断、有潜台词，别一问一答像审讯。
   - 每个人说话有自己的味道：阿蕖童言童语，李老栓话少、爱说农谚，族叔阴阳怪气，赵里正和稀泥，孟县尉不耐烦，贾福笑面虎。
   - 少用对话交代信息，信息能用动作、环境交代的就别让人物念出来。

1.6. **唐朝的味道**：每章至少写到一两样这个时代特有的东西，比如夯土版筑的墙、苫草屋顶、直棂窗、幞头、圆领袍、蹀躞带、胡禄、横刀、坞堡的马面和角楼、粮仓的囷和廪、坞门的晨鼓暮鼓。融在动作和场景里，别列清单。素材见 `设定/01-时代背景与考据备忘.md` 第八节。

1.7. **网梗与反套路**：主角是 2026 年穿过去的网民，心里吐槽可以用网络梗（如"不讲武德""芭比Q了""家人们谁懂啊""格局打开"），也可以拿穿越文的套路开涮（"按套路这时候该'叮'一声了"）。每章三五处，**放在内心独白里**；偶尔说出口，让唐朝人听得一愣，当笑料用。
2. **金手指边界**：主角是历史爱好者，不是工程师。他知道"有这个东西、大概怎么做"，港口能给他样品，但具体工艺和量产靠工匠反复试错。这样主角的发明更可信，也能带出配角。
2.5. **信任要有凭据**：主角得到别人的信任、权力、资源，必须有对方能亲眼验证的证明（抽检、试验、当场兑现、亲身经历），不能只靠"赌一把"或别人的一句推荐。验证的过程本身就是爽点。
2.6. **朝廷与配角不降智**：唐军、秦王府、地方官都有自己的办法和能人，而且一直在做。主角是补位、提速、把事做细，不是唯一的救星。写主角出彩时，同时写出别人在做什么、卡在哪里，主角的高明在比较中体现。
3. **反派不降智**：豪强、门阀、东宫的人都有自己的算计，主角要靠信息差和执行力赢，而不是靠对方犯蠢。
4. **历史大势基本不变**：玄武门、渭水之盟、灭东突厥等大事照常发生，主角改变的是细节、个人命运和"本不该那么惨"的地方。
5. **考据标记**：设定里写着【待核】的内容，正式成稿前要再查一次。
