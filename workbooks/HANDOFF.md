# 日语助词练习册：交接文档

清空对话（/clear）后，新对话先读这份文档再继续工作。每做完一步就更新这里。

## 目标

做一本可打印的 PDF 日语助词练习册，在网上用美金定价出售，作为被动收入。

- **用户：** 不会编程，不会英文，正在学日语（N4，标日初级）。每天学习 3 小时，其余时间自由安排。
- **分工：** Claude 负责内容、排版、生成 PDF 和文案。用户负责核对日语、注册平台、上架。

## 已定的决定

- **语言：** 卖**英文版**（英文说明 + 日语），读者是英语母语的日语初学者。书名用 **Particle Power**。
- **中文对照版：** 每做一部分英文内容，都同步更新 `workbook-zh.html`。它只给用户核对用，**不出售**，因为用户看不懂英文。
- 中文版商品（卖给华语读者）以后可以作为第二个产品。
- **级别：** N5（在用户已掌握的范围内，用户能自己核对）。
- **版权：** 例句和题目全部原创，不照搬《标准日本语》。
- **平台：** **Gumroad**（已注册）。Payments 设置里国家选 China 后，收款方式**只有 PayPal**（截图确认，没有银行卡选项）：Gumroad → PayPal（收 2%）→ 用户在 PayPal 里提现到国内一类储蓄卡（每次提现另收手续费，大约 35 美元，以 PayPal 显示为准，建议攒多了再提）。手续费：自己带来的客户每单 10%+$0.5，另加刷卡费 2.9%+$0.3；平台推荐来的客户抽 30%；余额满 $100 才提现。之后可能要填 W-8BEN 税表。Etsy 不接受中国大陆新店铺，不考虑。

## 现状

文件都在 `workbooks/particles/`：

| 文件 | 说明 |
|---|---|
| `workbook.html` / `particle-workbook-sample.pdf` | 英文版样稿，8 页（は・が・を） |
| `workbook-zh.html` / `particle-workbook-sample-zh.pdf` | 中文对照样稿，8 页，只供核对；用户已核对，回复"没问题" |
| `full.html` / `particle-power-full.pdf` | **英文完整版**（内容已写完，共 36 页）。中英文写在同一个文件里：英文放 `<en>…</en>`，中文放 `<zh>…</zh>`，日语两版共用 |
| `full.html#zh` → `particle-power-full-zh.pdf` | 完整版的中文对照版，只供用户核对 |
| `style.css` | 完整版的样式（样稿的 CSS 抽出来的）。页码自动编号，加页不用改数字 |
| `build.sh` | 下载字体并用 Chromium 生成全部 4 个 PDF：`./build.sh` |
| `listing/listing.md` | **上架材料**：要复制到 Gumroad 的英文文案（附中文翻译）、上传哪些文件、定价 |
| `listing/*.png` | 商品图：`thumbnail.png`（600×600）、`preview-1`～`5`（1280×720）。用 `listing/build-previews.sh` 从 PDF 重新生成（版式在 `listing/previews.html`） |
| `listing/pinterest.md` / `listing/pins/*.png` | **Pinterest 推广材料**：个人资料、图板、4 张竖版图钉（1000×1500）的英文标题和描述（附中文）。图用 `listing/build-pins.sh` 生成（版式在 `listing/pins.html`） |

目录页的页码是脚本自动算的：目录里写 `data-to="id"`，对应页的 `<section>` 加同名 `id` 即可。

检查工具：用 Chromium 打开 `full.html#check`（中文版用 `#zh,check`）并 `--dump-dom`，`<body data-overflow>` 会列出内容压到页脚的页（第 1 页封面报 +4px 是误报）。

设计：Letter 纸张尺寸，白底，只用一种强调色（印章红 #c0412b，只给助词用），所有汉字都标假名，每课的结构是"核心概念 → 句型 → 例句 → 提示框 → 练习"。

## 下一步：英文完整版

1. **完整版内容**（大约 30～40 页），写在 `full.html` 里，每课都要 `<en>` 和 `<zh>` 两份：
   - 封面、入门页（助词总览、使用方法）
   - は・が・を（沿用样稿）
   - 新增：に・で・へ・と・も・の・か・から/まで，每个助词一页讲解、一页练习
   - 对比专题：に 和 で、へ 和 に
   - 2 次综合复习测试
   - 一页助词速查表
   - 答案
2. **用户核对：** 每做完几课，就把对应的中文对照版发给用户，让用户做题、对答案。
3. **上架材料：** 英文商品标题和描述（附中文翻译给用户看）、3～5 张预览图、定价建议。
4. **用户注册平台并上架：** 用户靠浏览器翻译加截图问 Claude。
