# 人物小传

## 主角

### 韩霁（名字暂定）

**穿越前**
- 2026 年，34 岁，县级物流公司的仓储运营主管，干了十年。
- 农村长大，种过地，后来出门打工，自学考了证，一路做到主管。
- 业余是唐史爱好者，在历史论坛混了多年，通读过《资治通鉴》唐纪，对武德、贞观两朝如数家珍。
- 未婚，父母健在。穿越那晚加班到深夜，回到出租屋读《通鉴》，读着读着睡着了。

**穿越后（魂穿原身）**
- 武德二年，34 岁，绛州龙门县韩家村人。
- 隋朝府兵出身。大业八年随军征辽东，渡过辽水的三十万大军里，他是活着回来的两千多人之一。左腿中过箭，阴雨天会疼。
- 回乡后娶妻，妻子前年病逝，留下女儿阿蕖。
- 原身沉默寡言，村里人叫他"韩闷子"，被族叔和豪强欺负也不吭声。
- 家里有四十亩薄田、二十来石存粟，还有一笔被族叔做了手脚的"债"。

**性格**
- 34 岁的成年人，不冲动，不中二，**稳**。
- 遇事先算账：算粮、算人、算时间、算风险。
- 嘴上客气，下手狠；对自己人极好，对敌人不留后路。
- 有一点现代人的道德底线：不屠城，不虐俘，不卖人口。这是他和这个时代格格不入的地方，也会带来冲突。
- 幽默感偏冷，常在心里吐槽。

**成长线**
1. 卷一：保住女儿和粮食 → 被秦王府看见
2. 卷二：有了产业 → 成为一方豪商
3. 卷三：进入长安 → 卷入权力中心
4. 卷四：选择站队 → 生死一搏
5. 卷五：从商人到能臣 → 用仓储体系救一国之灾
6. 卷六：从能臣到开拓者 → 把大唐的货卖到天边

**外挂**：箭疤与残卷（详见 `设定/04-外挂：箭疤与残卷.md`）。脑中有一部《通鉴·唐纪》可以翻阅；左腿箭疤会预警致命危险；真到必死之时一定能活下来，代价是被撕掉一段未来的记忆。

**核心矛盾**：他越改变历史，就越失去"先知"的优势。到卷四，玄武门的细节已经和史书不一样，他第一次真正需要靠自己的判断赌命。

## 家人

### 阿蕖（韩蕖）
- 9 岁，主角的女儿。
- 机灵，嘴甜，能吃苦。母亲死后跟着闷葫芦父亲过日子，早熟。
- 是主角在这个时代扎根的第一根锚。最初主角对她是责任，后来是真正的父女。
- 成长线：识字 → 帮着记账 → 长大后成为商号的"小东家"。

## 感情线

> 目前设计为**一正一副**。如果你想要单女主，可以把康妙娜改成纯合作伙伴。

### 柳七娘（柳蘅）——正宫
- 26 岁，河东柳氏旁支的女儿，在家排行第七。
- 嫁过人，丈夫死于隋末兵乱。回娘家后，撑起了家里在绛州的布帛铺。
- 精明、算账快、嘴不饶人，看不起"泥腿子"，也看不起只会吟诗的世家子。
- 与主角初遇是一场交易上的斗智：他要绢，她要粮，双方互相压价，最后她输了半筹。
- 感情线：对手 → 合伙人 → 知己 → 夫妻。
- 她的困境：柳氏本家想把她再嫁出去换取利益；寡妇经商被宗族视为丢脸。

### 康妙娜——副线（卷三登场）
- 22 岁，粟特人，长安西市康氏胡商的女儿。
- 会说汉话、突厥话、粟特话，骑马射箭不输男人。
- 父亲的商队遭人陷害，她找上主角合作。
- 是主角打通西域商路、获取突厥情报的关键人物。
- 感情线：利用 → 信任 → 托付。
