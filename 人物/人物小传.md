# 人物小传

## 主角

### 韩霁（名字暂定）

**穿越前**
- 2026 年，34 岁，县级物流公司的仓储运营主管，干了十年。
- 农村长大，种过地，后来出门打工，自学考了证，一路做到主管。
- 业余是唐史爱好者，看过不少通俗唐史，大事记得清楚，细节记不住。
- 未婚，父母健在。穿越前三天在望潮港的驻港仓库加班盘点，那晚凌晨一点回到出租屋，泡了碗面，翻着一本唐史睡着了。

**穿越后（魂穿原身）**
- 武德二年，34 岁，绛州龙门县韩家村人。
- 隋朝府兵出身。大业八年随军征辽东，渡过辽水的三十万大军里，他是活着回来的两千多人之一。左腿中过箭，阴雨天会疼；右手拇指在辽东冻掉了半个指肚（第二章借据手印的破绽）。
- 回乡后娶妻，妻子前年病逝，留下女儿阿蕖。
- 原身沉默寡言，村里人叫他"韩闷子"，被族叔和豪强欺负也不吭声。
- 家里有四十亩薄田、二十来石存粟，还有一笔被族叔做了手脚的"债"。

**性格**
- **人不犯我，我不犯人。** 不惹事，也不怕事。别人不来招他，他乐得关起门来过日子；谁要是犯到他头上，他会客客气气地、一笔一笔地把账算清楚，让对方长记性。
- **只想过自己的日子。** 没有争霸天下的野心，最大的愿望是种几亩地、养大闺女、冬天有口热饭。他一路往上走，不是因为想往上走，而是因为乱世不让人安生，他得护住自己的小日子。
- **幽默风趣。** 心里吐槽不断，嘴上也时不时冒出一两句俏皮话。越是紧张的场面，越能看见他苦中作乐。这份幽默也是他在异乡撑下去的方式。
- 34 岁的成年人，不冲动，不中二，**稳**。遇事先算账：算粮、算人、算时间、算风险。
- 有现代人的道德底线：不屠城，不虐俘，不卖人口。这是他和这个时代格格不入的地方，也会带来冲突。
- 心软，尤其对孩子和老人。嘴上说"不管闲事"，最后总是管了。

**成长线**
1. 卷一：保住女儿和粮食 → 被秦王府看见
2. 卷二：有了产业 → 成为一方豪商
3. 卷三：进入长安 → 卷入权力中心
4. 卷四：选择站队 → 生死一搏
5. 卷五：从商人到能臣 → 用仓储体系救一国之灾
6. 卷六：从能臣到开拓者 → 把大唐的货卖到天边

**外挂**：望潮港（详见 `设定/04-外挂：望潮港.md`）。清醒时闭眼一念，就能整个人进入一座无人的现代货运港口，他在里面待多久，外面都不过时间。摸得到的东西都能带出来，但放不回去。遇到危险就进港，穿上防刺服、拿上盾牌再出来；受了伤就进港治好再出来。

**核心矛盾**：他只想过小日子，乱世偏不让。他越改变历史，记得的那些大事就越不灵。到卷四，玄武门的细节已经和史书不一样，他第一次真正需要靠自己的判断赌命。

## 家人

### 阿蕖（韩蕖）
- 9 岁，主角的女儿。
- 机灵，嘴甜，能吃苦。母亲死后跟着闷葫芦父亲过日子，早熟。
- 是主角在这个时代扎根的第一根锚。最初主角对她是责任，后来是真正的父女。
- 成长线：识字 → 帮着记账 → 长大后成为商号的"小东家"。

## 感情线

> 目前设计为**一正一副**。如果你想要单女主，可以把康妙娜改成纯合作伙伴。

### 柳七娘（柳蘅）——正宫
- 26 岁，河东柳氏旁支的女儿，在家排行第七。
- 嫁过人，丈夫死于隋末兵乱。回娘家后，撑起了家里在绛州的布帛铺。
- 精明、算账快、嘴不饶人，看不起"泥腿子"，也看不起只会吟诗的世家子。
- 与主角初遇是一场交易上的斗智：他要绢，她要粮，双方互相压价，最后她输了半筹。
- 感情线：对手 → 合伙人 → 知己 → 夫妻。
- 她的困境：柳氏本家想把她再嫁出去换取利益；寡妇经商被宗族视为丢脸。

### 康妙娜——副线（卷三登场）
- 22 岁，粟特人，长安西市康氏胡商的女儿。
- 会说汉话、突厥话、粟特话，骑马射箭不输男人。
- 父亲的商队遭人陷害，她找上主角合作。
- 是主角打通西域商路、获取突厥情报的关键人物。
- 感情线：利用 → 信任 → 托付。
